## 本轮目标与边界

保留全屏呈现与16:9战斗视野，重新组织游戏内的战斗信息、对话和暂停面板。延续已确认首页的深青、暖金、象牙白配色，让生命、威胁与当前行动更清楚，画面中央留给角色、平台和攻击预警。

本轮只新增本目录的设计图、审核页与说明，未修改 index.html、运行时 JS/CSS、存档格式、构建或基础设定。图片是布局概念示意；场景、人物造型、地面高度、镜头与战斗距离仍沿用游戏实际素材和规则，不依据示意图重做美术或关卡。图中的生命、份额与冷却为同一示例时刻的数据，不是新增固定数值。

## 1. 战斗主界面

| 位置 | 布局 | 显示与交互 |
| --- | --- | --- |
| 左上 | 当前角色的大头像与血条，队友在下面缩成一行 | 当前出战有金框与文字标记；保留1/2与Tab切换。未加入显示“尚未加入”，倒下显示“已倒下”，不只依赖颜色 |
| 头像下方 | 按所属角色显示异常与结界小标记 | 首轮展示已有中毒层数、减速、结界耐久/剩余时长；后台角色也可读。无状态不占行。不把未来瘴气、道具等画成已实现能力 |
| 上中 | 首领名称、血条、阶段提示 | 仅出现存活首领时显示；普通探索留空。与左侧队伍、右侧目标不重叠 |
| 右上第一行 | 全屏、声音、暂停三个图标 | 暂停标注Esc；工具具备文字辅助标签，点击区至少44×44 CSS像素 |

| 左下 | 四魂之玉图标与双方份额 | 玉碎且争夺开始后显示真实我方/敌方份额；此前显示“尚未玉碎”，不显示示例2%。点击打开已暂停的四魂页，不公开未侦察情报 |

| 右下 | Tab切换与“? 操作”小入口 | 取消常驻的整段按键说明。操作入口打开暂停菜单的操作说明，首次教学按关卡事件短时出现 |
| 场景交互点旁 | E＋动作名称 | 仅靠近可交互位置时出现；保留原角色资格判定。全局目标说明去掉重复的长按键串 |

桌面原型以1600×900为示意基准；实际HUD采用可读字号与边距，不将界面当整张图等比缩到手机。桌面安全边距约2.5%～3%，主文字建议16～20 CSS像素，生命数字至少14像素。战斗中心不摆常驻导航、大头像或系统提示弹窗。

普通探索隐藏首领条。低血量以颜色、图标和“生命偏低”文字提示，避免高频闪烁。短时获得碎片、收录图鉴和检查点消息放在上中预留区域；首领条出现时移到其下，并限制为一条，不遮住目标或人物。

## 2. 暂停页：旅途手记

暂停后，世界压暗，打开占屏约86%宽、83%高的统一面板；不是额外的剧情或任务系统。顶部固定五个页签，底部固定“继续旅程”。

| 页签 | 内容 |
| --- | --- |
| 旅程 | 当前篇章与场景、现有目标、最近检查点、本幕信物、双方份额摘要 |
| 伙伴 | 现有人物阶段、生命/攻击/灵力或妖力、已解锁技能与武器、已完成剧情成长。没有经验、技能点或升级按钮 |
| 四魂之玉 | 既有双方与未归属份额、已知线索与已知归属。敌方具体行动仍遵循情报规则 |
| 妖怪图鉴 | 沿用已遭遇/击败的收录状态；左侧列表或网格，右侧阅读详情 |
| 设置 | 声音、全屏、操作说明、导入/导出存档；现有资源验证场入口保留为次要链接，不占战斗HUD |

“旅程”内底部提供继续、检查点重试和返回首页。没有检查点时明确显示“从本幕起点重试”，避免误称已保存检查点。检查点资料只来自真实已触发记录；不会把当前站位、当前HP或刚打开菜单说成已存为检查点。

Esc关闭菜单并继续；页签切换不恢复世界计时。从左下碎片或操作帮助进入时，也使用同一暂停状态。切换页签保留可用的键盘焦点，菜单内Tab不触发战斗切人；关闭后焦点回到游戏。导入覆盖仍保留既有确认流程。

## 3. 剧情对话

对话期间暂停世界，隐藏技能、虚拟按键、目标与首领条，保留淡化的队伍生命摘要。底部对话框宽约90%、高约23%～26%，左侧小头像，右侧姓名、句序和2～3行文字；右下继续按钮及Enter/E提示固定。

对话全文保持可见，不强制依赖逐字动画；长句按实际容器换行，必要时扩大框高并在框内滚动。旁白使用已有符号，无人物时不空留大头像。点击继续与现有Enter/E/Space继续逻辑一致，不新增跳过剧情或未有自动播放。

审核页中的对话状态是确定布局用的线框；沿用已有对白“红色的骷髅……那里的妖气最强！先打碎那些发丝结点！”，不是新剧情文案。

## 4. 触屏与窗口适配

- 桌面与横屏保持完整16:9游戏视野；更宽或更高的窗口用深色留边容纳，不拉伸、裁掉平台或额外扩大视野。
- 手机横屏压缩顶部留白，队伍改成两张紧凑横排卡，目标最多两行，首领条在顶部中间独立预留。
- 触屏用左下“左、下、右”控制，右下两行六键“技能一、技能二、闪避 / 切换、跳跃、攻击”，替代桌面技能条；每个真实触点至少44×44 CSS像素。下键与攻击可同时按，保留上挑/下砸操作。
- 接近交互点时，在下中显示可点的动作提示；补齐现有触屏入口中缺少的第二技能与场景交互，使用现有能力与资格规则。
- 左下四魂摘要在触屏移至目标下的一行，避开移动区；不同时保留两套操作面板。
- 手机竖屏保留完整16:9场景，将操作区放在其下方的余留区域，上方显示紧凑状态；可提示横屏体验，但不强制锁定方向。
- 小屏暂停页为上下结构，页签可横向滚动，内容独立滚动，继续/关闭始终可达。对话沿场景底部或下方余留区展开，正文字号不无限缩小。
- 尊重安全区、减少动态效果偏好；生命、冷却、选中和异常均有文字/图形辅助。

## 5. 过关与失败面板

保持现有结果与星章规则，只统一边框、字号与按钮层级。过关：篇章/场景结果 → 星章及已有统计 → 下一幕/回顾篇章主按钮；失败：失败原因/队伍状态 → 检查点或本幕起点重试主按钮。不开新奖励或货币，不把前三篇完成写成集齐四魂之玉。

## 用户本轮审核点

1. 是否采用“出战大卡＋队友小卡”的左上布局，以及首领条居上中的分区？

3. 是否采用五页签的“旅途手记”，作为游戏内查看资料和设置的统一入口？
