# 人物面板 UI v0.3：上衣与下衣独立装备格
设计日期：2026-10-28。状态：按用户要求修订的高保真设计稿，尚未接入游戏。

[打开最新版查看页](review.html) · [装备效果图](character-equipment-v3.png) · [完整提示词](prompts-v3.md) · [上一版页面](review-v2.html)

## 本次变更
用户要求将衣装部位拆分为上衣和下衣。新版以两个独立部位格替代原衣装格，分别选择、查看与更换。
整体保留公用道具一级菜单、人物专属装备归属、安全地点换装和选中部位的右侧详情。

## 七个部位与排列
- 人物左侧，自上而下：头部、上衣、下衣、手部。
- 人物右侧，自上而下：饰物、武器、足部。
- 上衣显示独立红色上装图标与“初始上衣”；下衣显示独立红色裤装图标与“初始下衣”，不再使用整套衣装图标。
- 武器仍为选中的铁碎牙；头部、手部、饰物、足部仍为空位。
- 示意统计同步更新为已装备3／7：初始上衣、初始下衣、铁碎牙。
- 左侧四格重新排布，右侧三格和人物、详情区保持同一视觉风格；底部操作完整保留。

## 交互与内容边界
上衣和下衣分别作为独立选择对象，对应详情、更换入口与该人物的适用候选清单；替换其中一个部位只影响该部位，沿用安全地点可换、非安全地点仅可查看的规则。
公用道具继续放在旅途手记一级菜单，不回到人物装备页。
铁碎牙形态经历与人物当前形象沿用上一版。初始上下衣图标用于布局，不新增装备属性、掉落、材料、套装奖励或剧情授予配置；实际装备记录与候选清单在正式接入时配置。
本轮交付仅为效果图和查看页，图内格子暂不执行游戏操作；此前未确定的其他部位细则仍沿用讨论稿状态。
