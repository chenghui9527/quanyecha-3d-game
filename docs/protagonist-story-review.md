# 主角线剧情章节 v1.0

版本：1.0 · 确认与保存日期：2026-10-26 · 状态：章节结构已整体审核通过，正式作为剧情基础设定的章节明细；犬主01～03已接入可玩首版，其余逐篇任务与数值继续细化。

用户已确认双时间轴的10阶段、51篇主线与22条支线系列，以及对应的人物、成长和故事节点。本文纳入[剧情基础设定 v1.0](story-system-design.md)，作为主角线正式章节明细，保留原编号与篇章内容。依据[动画关键节点参考](anime-story-milestones.md)及其中的官方剧情来源，继续遵守[四魂之玉系统v1.0](shikon-jewel-system-design.md)和[人物成长v1.0](character-growth-design.md)。

篇章数量用于组织事件，不代表关卡数、开发排期或通关时长。人物登场、加入关系与可操作资格分别审核；任务目标不预设成功，原作失玉、背叛和死亡不自动变成玩家必然结果。

双方共享同一批真实碎片。任何一方实际集齐立即确定胜负，不要求走满本稿。支线不得藏住唯一通关必需能力；含真实碎片的可选事件必须另配可达的替代夺取路径。暂停、对话、离线仍停止计时。

实现补充（2026-10-26）：前三篇的六幕流程、成长、碎片、存档迁移与首版表现见[可玩首版配置](opening-three-chapters.md)。后续篇章仍以本文确认内容为依据。

## 路线定位

以犬夜叉、戈薇及逐步加入的伙伴为叙事核心：相遇 → 寻玉 → 识破奈落 → 人物成长 → 救援与争夺 → 最终归玉。保留上一稿的51个事件篇章，逐篇独立编号“犬主01～犬主51”；支线“犬支01～犬支22”。

“主线幕间”是所选路线中的必要叙事，不等于玩家能操控独立人物或开启完整上帝视角；具体信息呈现按人物当时可知内容配置。
