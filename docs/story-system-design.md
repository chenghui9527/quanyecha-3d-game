# 剧情基础设定 v1.0：双阵营与章节

版本：1.0 · 基础设定确认日期：2026-10-26 · 状态：用户已确认作为游戏基础设定；两线章节已整体通过，犬主01～03试玩基本通过，后续内容继续细化。

## 设计地位与确认范围

本文件是[游戏基础设定总纲 v1.0](game-design.md)中的剧情基础规范，以用户通过的主角线v0.1、奈落线v0.2及其双时间轴为确认基准。用户在前三篇试玩基本通过后，明确将这套剧情设计确认为游戏基础设定。正式纳入10个同期阶段、主角线51篇主线与22条支线系列、奈落线39篇主线与12条支线系列，共90篇主线与34条支线系列。

阶段划分、篇章顺序与名称、主支线归属、剧情目标、人物关系和成长故事节点，以及奈落线的游戏补写方向均已确认。保留“犬主01～犬主51”“犬支01～犬支22”“奈主01～奈主39”“奈支01～奈支12”的独立编号，后续逐篇细化以这些编号引用。

各篇完整剧情明细分别保存于[主角线剧情章节 v1.0](protagonist-story-review.md)与[奈落线剧情章节 v1.0](naraku-story-review.md)。本文提供阶段对照、全部篇章目录、系统衔接规则与逐篇配置要求；原文件名保留，以兼容既有链接。

本设定与[基础战斗 v1.0](combat-system-design.md)、[人物成长 v1.0](character-growth-design.md)、[四魂之玉 v1.0](shikon-jewel-system-design.md)共同构成游戏的四项基础规范，约束后续人物、任务、关卡、成长、碎片、AI、界面及存档的设计和实现。动画事实仍以[动画关键节点参考](anime-story-milestones.md)及已保存的来源为依据，游戏补写不因章节获得确认而变为动画既有事实。

## 基础设定与试玩确认边界

- 已确认的基础内容包括阵营与信息边界、剧情组织层级、阶段与全部主支线目录、人物与成长故事节点、奈落开篇顺序，以及剧情同四魂之玉、成长、AI和存档的衔接规则。
- 犬主01～03共六幕的基本流程已获用户试玩认可，后续篇章可沿用其按剧情成长、互动取得碎片、事件推进敌方行动和检查点一致恢复的组织方式。
- [前三篇配置](opening-three-chapters.md)中的具体份额、属性、倍率、时长、首领表现与美术继续调试；其余章节继续配置任务、对白、操作资格及具体分支，正式章节结构作为共同基础。
- 确认范围覆盖两套完整故事结构；当前可玩范围为主角线前三篇，奈落可玩路线、其余主支线与完整系统能力继续制作。

## 剧情组织与两线关系

- 层级采用“阵营路线 → 阶段 → 篇章／支线系列 → 任务与关卡 → 剧情事件”。一篇可包含多个任务、场景与关卡，支线系列可跨多个阶段，具体数量与长度待配置。
- 玩家选择犬夜叉或奈落阵营体验该线剧情，对方由AI行动。同一世界事件可承接两线不同目的、人物、任务与结果，不要求篇章一一镜像，也不要求双方按篇章编号同步推进。
- 主线承接四魂争夺、核心人物加入、必需成长、敌方关键变化、必要独立人物因果与最终胜负；支线承接可选冒险、人物关系、往事、调查及非通关必需成长。
- 人物登场、同行、临时交易、受控、分身产生和可操作资格分开记录。已确认故事节点不自动赋予操作资格、人物大等级或属性数值。
- 桔梗、杀生丸一行、钢牙等独立人物的必要因果通过遭遇、调查、对话或主线幕间交代；所选路线中的幕间不等于开放完整观战。双方收集进度公开，行动、位置与人物秘密仍按情报条件揭示，一期第三方视角仍仅提供进度比对面板。
- 阶段用于剧情先后与同期对照。动画集数是素材范围，等距时间轴不表示实际游玩时长；篇章总数也不等于开发排期或必须完成的关卡数。

## 与四魂之玉、成长和AI的衔接

| 模块 | 章节配置必须遵守的规则 |
| --- | --- |
| 碎片真实归属 | 双方争夺同一批真实碎片，总份额固定、归属唯一；两线事件使用同一归属结果，重玩或重复结算不复制碎片 |
| 剧情结果 | 目标不预设成功；沿玩家争夺与世界事件的实际结果承接，不把失玉、背叛或死亡一律强制恢复为动画结局 |
| 支线与通关 | 必需人物、破界、净化或解毒准备和武器成长有主线可达路径；含真实碎片的可选支线须配置不做时的真实后续归属、转移事件和替代夺取路径 |
| 成长事件 | 按指定任务或剧情提升大等级，技能、武器、装备按节点或特定人物解锁；奖励只结算一次，不增加人物经验或技能点，不把每次人物登场都算成长 |
| 情报边界 | 双方收集比例公开；持玉者、位置、计划、秘密和敌方成长按实际接触、调查或剧情揭示，不随阶段对齐自动共享 |
| AI推进 | 按已配置的剧情阶段或世界事件触发真实行动及结果，可被干预也可失败；不因查看时间轴、等待现实时间或单纯到达某一篇章编号就自动增玉 |
| 暂停与恢复 | 暂停、对话、离线停止计时；剧情事件、成长结算、碎片归属、情报与AI结果按对应检查点和存档一致恢复 |
| 终局 | 任意一方集齐立即确定胜负，允许更早进入结局；攻坚、救援与最后争夺在集齐前或同场处理，不强制走满90篇，也不增设集齐后的仪式或守时门槛 |

犬主48与奈主36的琥珀碎片事件沿实际归属处理，不照搬动画强制奈落获得完整玉。主角线阶段10的犬主49～51与奈落线阶段10的奈主37～39均按这一胜负规则衔接；奈落胜利结局为已确认的游戏改编方向，具体文本继续编写。
