## 已确认：伤害属性、攻击来源与防御分类

实际伤害属性分为物理、妖力、灵力；普通攻击、技能、道具分别记录为攻击来源。攻击道具根据自身性质归入物理、妖力或灵力，不单设第四类道具伤害。

| 攻击来源 | 判定依据 | 伤害属性 |
| --- | --- | --- |
| 普通攻击 | 普通攻击统一归类 | 物理 |
| 技能 | 技能为妖力属性 | 妖力 |
| 技能 | 技能为灵力属性 | 灵力 |
| 道具 | 无妖力/灵力属性的普通攻击道具 | 物理 |
| 道具 | 道具属于妖物 | 妖力 |
| 道具 | 道具属于灵物 | 灵力 |

防御手段分为三类：结界、自身防御、衣物防御。

普通攻击道具的原始伤害由道具自身威力决定，再经过目标物理防御减免；附带中毒等效果独立结算。纯治疗、纯施毒等功能道具按对应效果处理。

## 已确认：主体单一属性与附加效果

- 首版每次攻击的主体伤害只有一种属性，附加状态与其伤害按各自规则独立结算。
- 普通攻击主体使用物理伤害；技能主体使用对应的妖力或灵力伤害，多段技能各段沿用该技能属性；道具主体按自身性质确定属性。
- 中毒、邪气、瘴气等附加效果沿用既定规则。
- 例如带毒箭使用“物理伤害＋中毒状态”；附带邪气的攻击，其主体伤害与邪气的一次性妖力伤害分别处理。
- 不将同一攻击的主体伤害拆分为物理/妖力/灵力的混合分量；这一限制不取消已确认的附加效果独立结算。

## 已确认：原始伤害来源

| 攻击方式 | 原始伤害计算 |
| --- | --- |
| 普通攻击 | 物理攻击力 × 招式倍率 |
| 妖力技能 | 妖力强度 × 技能倍率 |
| 灵力技能 | 灵力强度 × 技能倍率 |
| 普通攻击道具 | 道具自身的物理伤害数值 |
| 妖物道具 | 道具自身的妖力伤害数值 |
| 灵物道具 | 道具自身的灵力伤害数值 |

- 角色分别配置物理攻击力、妖力强度、灵力强度，使用对应属性产生原始伤害，再进入结界或本体承伤流程。
- 攻击道具依靠自身效力，同一道具由不同角色使用时基础伤害一致。
- 中毒、邪气、瘴气的伤害数值按施加来源配置的毒性或状态强度单独记录。中毒维持既定的每秒毒性掉血规则，邪气/瘴气采用下述已确认的妖力抗性减免规则。
- 具体属性值、招式/技能倍率和道具效力数值后续调试。

## 已确认：结界

### 开启与属性

- 结界属于防御技能，可以由灵力、妖力驱动，或通过道具直接开启。
- 驱动来源与防御能力分别定义。对物理、妖力、灵力伤害的抵抗能力由结界自身属性决定，具体参数待定。
- 结界使用独立耐久承受伤害；衣物与自身防御不参与结界承伤计算。

### 生命周期

| 项目 | 规则 |
| --- | --- |
| 同时存在 | 同一目标最多有一个有效结界 |
| 重复开启 | 新结界成功生效后替换旧结界，使用新耐久与持续时间，耐久不叠加 |
| 开启方式 | 技能结界采用冷却制；道具结界每次消耗1件，维持期间不持续扣资源 |
| 耐久恢复 | 默认不自动恢复，重新施放产生新结界 |
| 结束条件 | 耐久归零、持续时间结束、主动解除、受保护目标死亡，或过关/切换场景 |
| 行动影响 | 生效后允许移动、攻击、闪避，这些行动不会解除结界 |

- 成功生效时开始冷却或扣除道具；生效前被打断不消耗。
- 提前解除或被攻破，已消耗的道具与冷却保留。
- 新结界未成功生效时，旧结界继续按原规则存在。
- 具体耐久、持续时间与冷却数值待定；切人、暂停、过关和存读档按下文已确认的状态生命周期处理。

### 保护与破界

- 结界有效期间，受保护目标不承受被结界拦截的外部攻击伤害。必须先攻破结界，才能通过后续命中伤害本体。
- 结界耐久归零时破碎；破界这一击的剩余伤害不溢出到本体。
- 例如结界剩余20点耐久，受到100点伤害：结界破碎，本体不扣血。下一次独立命中才进入本体防御结算。
- 多段攻击逐段判断：某一段破界后，之后到达的独立命中可以伤害本体；破界的同一段不再对本体结算伤害。
- 对可被结界拦截的外部命中，结界存在时只结算结界承伤；未被结界拦截的影响按对应本体规则结算。已有异常持续伤害走独立流程，不因开启结界而改为消耗结界耐久。

### 异常与环境

- 结界默认拦截直接攻击；被拦截攻击附带的中毒、眩晕、束缚等效果无法施加到本体。
- 隔绝瘴气等环境侵害需要结界具备相应能力。
- 开启结界不自动清除或暂停本体已有异常；已有中毒等状态继续运行。解除异常可以作为特定结界技能的额外能力。
- 上述规则确定结界与附带效果的关系；中毒、邪气、瘴气的叠加与解除规则已确认，具体伤害、持续时间等参数待配置。

## 已确认：衣物防御

- 用户选择A方案：衣物在穿戴期间持续提供防御属性，对受到的伤害进行减伤。
- 基础衣物机制不设独立耐久，不需要先打破衣物才能伤害本体，也不因普通受击逐渐破损或失去防御。
- 结界不存在时，衣物与自身防御共同参与本体伤害结算，按下述规则依次减伤。

## 已确认：自身与衣物的共同减伤

- 按物理、妖力、灵力三类伤害分别防御。自身和衣物均可具有这三类防御属性，具体强弱各有区别。道具伤害归入其对应属性后使用同一套减伤规则，不单设道具防御属性。
- 两层使用对应伤害类型的百分比依次减伤：衣物先削减伤害，自身防御再削减剩余伤害；两层减伤比例不直接相加。
- 基础计算方式：伤害 = 原始伤害 ×（1 − 衣物对应类型减伤率）×（1 − 自身对应类型减伤率）。仅在伤害可以命中本体时使用；三类综合减伤率均需应用80%的常规上限，特殊伤害免疫另行判断。
- 例如100点物理伤害、衣物物理减伤20%、自身物理减伤30%，实际生命伤害为100 × 80% × 70% = 56点。
- 各项防御属性的具体数值待配置，常规上限与精度规则见下文“数值边界”。主体使用单一属性，附加效果分别按各自规则处理。

## 已确认：灵力抗性与妖力抗性

- 灵力抗性只减少对应的灵力伤害，包括灵力技能与灵物道具造成的灵力伤害。
- 妖力抗性只减少对应的妖力伤害，包括妖力技能与妖物道具造成的妖力伤害。
- 两种抗性对应前述妖力/灵力的百分比减伤属性，沿用衣物与自身依次减伤的公式，不作为额外重复计算的一层减伤。
- 两种抗性只影响伤害数值，不影响附带控制或异常状态的施加概率、持续时间、强度，也不提供异常解除能力。
- 中毒、束缚、眩晕、邪气等效果的抵抗与解除按各自规则处理；邪气/瘴气的伤害属性与减伤见下文，中毒维持原约定。

### 已确认：综合抗性上限与特殊免疫

- 常规灵力综合抗性、妖力综合抗性分别以80%为上限。先计算衣物与自身共同提供的减伤率，再应用上限。
- 对应属性综合抗性 = min（80%，1 −（1 − 衣物对应抗性）×（1 − 自身对应抗性））。
- 实际对应属性伤害 = 原始伤害 ×（1 − 对应属性综合抗性）。
- 例如衣物与自身抗性各50%，综合抗性为75%；两者各60%时，基础综合抗性为84%，实际按80%计算。受到100点对应属性伤害时，分别扣除25点、20点生命。
- 特殊能力可以单独配置对某一伤害属性的完全免疫；该免疫使对应伤害为0，不通过普通抗性堆叠获得。
- 特殊伤害免疫沿用“只作用于对应伤害”的边界，异常与控制免疫按各自独立配置判断。
- 本体物理综合减伤率、结界自身三类减伤率也采用80%的常规上限；结界独立配置，具体规则见下文“数值边界”。

## 已明确：中毒、邪气、瘴气的基础定义

### 中毒

- 中毒只有持续掉血这一种负面效果，每秒扣血；不同毒性对应不同的每秒伤害。
- 中毒层数不设上限，可以持续累积；层数本身不触发死亡，每层到期仍按独立计时规则自然消退。
- 每层独立记录毒性与持续时间，分别计时、到期自然消退；新层不统一刷新其他层的剩余时间。
- 每秒伤害为当前所有有效中毒层每秒伤害之和；某一层到期后，该层伤害从后续结算中移除。
- 处理方式为毒性自行消退、服用解毒药、使用明确具有解毒效果的治疗技能，或由特殊人物的毒免疫能力避免中毒。
- 一份解毒药清除当前全部中毒层；用药不提供后续毒免疫，再次受到施毒仍可重新中毒。
- 中毒沿用按各层毒性每秒掉血的状态规则，不额外定义伤害属性或新增抗性减免规则。
- 具体毒性与时长、区域施毒间隔、哪些人物具有毒免疫及适用目标范围仍待讨论；基础施加规则见下文。

### 邪气

- 邪气造成一次性扣血与可叠加的虚弱状态。
- 虚弱每层降低5%的角色攻击伤害与5%的移动速度，最多各降低50%；适用范围与精度见下文“数值边界”。
- 虚弱不会自然消退，离开邪气来源后仍保留，直至被解除。
- 邪气必须通过普通灵力净化或特殊道具解除。
- 一次净化或使用一份对应道具，清除全部虚弱层数；已经扣除的生命不会因此恢复。
- 一次性扣血确认为妖力伤害，受到衣物与自身的综合妖力抗性减免；抗性不影响虚弱层数与净化要求。
- 邪气区域施加间隔待配置。首版沿用既定的净化/道具解除方式，不加入妖力临时压制。

### 瘴气

- 瘴气先直接扣除一部分生命，并附加持续掉血状态。
- 持续掉血必须通过灵力净化解除；离开瘴气来源后不会自行消退。
- 瘴气沿用已确认的灵力净化门槛与对应净化道具，妖力不作为解除途径，首版也不加入妖力临时压制。
- 净化必须满足以下任一条件：具备特殊灵力，或灵力等级足够高；具体等级门槛待定。
- 特殊人物可以具有瘴气免疫，免受瘴气造成的直接扣血与持续掉血；具体人物配置待定。
- 净化资格与灵力抗性分别判断，抗性本身不提供净化能力。
- 直接扣血与持续掉血均确认为妖力伤害，受到衣物与自身的综合妖力抗性减免。持续伤害每次结算使用当前综合妖力抗性；抗性不解除瘴气，也不改变净化资格。
- 重复接触按下文已确认规则处理；直接扣血的数值方式、持续掉血的频率/强度和具体源头净化配置待定。角色与区域源头的作用范围按下述净化规则分别标注。

### 与既有抗性和结界规则的衔接

- 灵力/妖力抗性继续只影响对应属性的伤害数值，不影响中毒层数、负面状态追加，也不提供压制或净化能力。
- 邪气的一次性伤害、瘴气的直接与持续伤害使用综合妖力抗性减免，沿用常规上限80%与特殊伤害免疫规则。中毒维持原约定；特殊人物可具有毒免疫或瘴气免疫，具体人物与其他目标的适用规则待定。
- 结界继续按既有规则拦截直接攻击及其附带效果；隔绝环境侵害需要相应能力。开启结界不自动解除已有状态。
- 首版不加入独立的妖力临时压制机制，妖力强度本身不暂停虚弱或瘴气持续伤害；妖力抗性减伤、结界隔绝和特殊人物免疫继续按各自规则生效。

## 已确认：中毒与邪气的重复施加

| 情况 | 状态施加规则 |
| --- | --- |
| 单次普通攻击 | 带有对应效果时，有效命中增加1层中毒或虚弱；同一次出手对同一目标不重复叠层 |
| 多段技能 | 伤害按招式设计分段结算；默认整次释放对同一目标最多施加1层状态 |
| 持续毒区、邪气区域 | 首次有效接触施加一次，之后按来源配置的固定间隔再次施加 |
| 短暂离开后重新进入区域 | 同一来源的施加间隔继续记录，重新进入不重置间隔 |

- 中毒每秒掉血本身不增加毒层；虚弱只有再次受到邪气影响时才增加。
- 是否有效施加遵守结界拦截、对应状态免疫及下述闪避无敌规则；受击本身不产生无敌。
- 具体区域间隔数值待定；瘴气重复接触按下述独立规则处理。

## 已确认：瘴气重复接触

| 情况 | 处理规则 |
| --- | --- |
| 首次接触 | 扣一次直接伤害，并附加持续掉血 |
| 持续停留 | 继续掉血，不反复触发直接伤害 |
| 离开来源 | 已有持续掉血保留，直到净化 |
| 离开后重新进入 | 可以再次触发直接伤害；同一来源设触发间隔，短暂进出不重置间隔 |
| 接触不同强度的瘴气 | 只保留一个持续掉血状态，持续伤害取较高值，较弱效果不覆盖较强效果 |
| 净化后再次有效接触 | 可以重新受到瘴气影响 |

- 不同来源的直接伤害分别结算；持续伤害不累加，最强效果保留至净化。
- 所有扣血继续按妖力抗性减免，瘴气免疫人物不受影响。
- 具体触发间隔数值待定；区域内净化后源头仍存在时，按原来源触发间隔重新判断影响，净化不重置间隔。

## 已确认：免疫与闪避

用户最新要求删除受击无敌机制，以下规则以这一修改为准，保留闪避无敌与独立配置的伤害/状态免疫。

| 情况 | 处理规则 |
| --- | --- |
| 闪避无敌期间 | 直接攻击无法有效命中，不扣血、不施加附带状态，也不消耗结界耐久 |
| 受到攻击后 | 不产生受击无敌，后续独立命中照常判断伤害与附带状态 |
| 已有中毒、瘴气持续掉血 | 正常结算，不被闪避无敌暂停 |
| 持续危险区域 | 闪避无敌不阻止区域接触，仍按区域规则施加效果 |
| 某类伤害免疫 | 只免除对应伤害，附带状态独立判断 |
| 毒免疫、瘴气免疫 | 阻止对应状态及其伤害，攻击携带的其他伤害照常判断 |

- 持续掉血和环境扣血不触发受击硬直。
- 本体的伤害免疫只保护本体，结界按自己的防御属性独立承伤。
- 受击无敌的时长、触发条件不再作为待配置项；单次命中去重与真实多段攻击分段结算仍按攻击规则处理。

## 已确认：死亡条件与事件顺序

- 死亡只由生命降至0触发，过量扣血后的生命按0处理。
- 中毒仅通过各层持续伤害之和消耗生命，不按层数直接判定死亡；不再设置首领的中毒层数即死适用特例。
- 事件先按实际发生时间先后处理。完全同一时刻发生时，按下列优先顺序处理。

| 优先级 | 处理内容 |
| --- | --- |
| 1 | 移除已经到期的效果 |
| 2 | 结算已经完成的解毒、净化、解控、治疗 |
| 3 | 逐次处理新的攻击命中、区域施加与状态叠加 |
| 4 | 结算到点的持续掉血 |

- 每次扣血后立即检查生命是否归零；死亡后停止接受后续伤害与普通治疗。
- 死亡和击杀收益只结算一次。

## 已确认：解除能力、作用对象与必经区域准备

- 用户明确要求相关危险区域不可绕行，玩家必须通过提前收集道具，或安排有治疗能力的角色应对。
- 关卡应在进入必经区域前提供对应道具的收集机会，或角色准备的条件。
- 关卡准备流程为：提前收集道具/安排治疗角色 → 进入危险区域 → 治疗或解除状态 → 继续推进。

| 状态 | 对应道具 | 角色能力 |
| --- | --- | --- |
| 中毒 | 解毒药 | 明确具有解毒效果的治疗技能 |
| 邪气 | 对应驱邪道具 | 普通灵力净化 |
| 瘴气 | 携带特殊灵力净化效果的道具 | 特殊灵力，或灵力等级达标的净化技能 |

- 回血与解除状态分别配置，治疗角色的技能应明确能处理哪些状态。瘴气净化道具以其携带的特殊灵力满足既定门槛。
- 角色净化可作用于自身或指定存活队员；清除区域源头需要能力明确支持。成功清除后，该源头停止施加影响。
- 源头仍存在时，按原触发间隔重新判断影响，净化不重置该间隔。
- 角色存活且能行动时可使用；施放完成时生效并结算消耗/冷却，完成前被打断不消耗。
- 明确标注“受控可用”的解控能力按其例外规则执行；其他操作遵守六类控制的行动限制。
- 净化默认移除状态，回血和临时免疫作为额外效果单独配置。
- 特殊人物既有的毒免疫、瘴气免疫继续生效。
- 具体等级门槛、技能作用范围/施放时长及源头的可净化配置后续确定。

## 已确认：数值边界

| 项目 | 规则 |
| --- | --- |
| 本体物理减伤 | 衣物与自身依次计算，综合上限80% |
| 本体灵力、妖力抗性 | 沿用综合上限80% |
| 结界自身减伤 | 独立配置物理、妖力、灵力三类防御，常规上限也为80% |
| 特殊伤害免疫 | 单独配置，对应伤害为0 |
| 虚弱 | 每层降低5%攻击伤害、5%移动速度，最多各降低50% |
| 生命范围 | 保持在0至最大生命之间，过量伤害或治疗按边界处理 |
| 伤害精度 | 实际计算保留小数，显示时再取整；不强制每次至少扣1点 |

- 本体对应类型综合减伤率 = min（80%，1 −（1 − 衣物对应减伤率）×（1 − 自身对应减伤率））。
- 虚弱影响角色普攻和攻击型技能伤害；治疗、净化资格与道具自身威力保持原规则。原始攻击伤害按虚弱系数修正后，再进入结界或本体承伤结算。
- 虚弱自身的攻击伤害/移速降低比例 = min（50%，虚弱层数 × 5%）。仅有虚弱时，3层使攻击伤害与移速各保留85%，10层及以上各保留50%；与其他减速并存时，移速按下文“控制叠加”取最强效果。
- 虚弱效果达到上限后，进一步受到邪气影响仍会受到一次性伤害。
- 中毒层数继续不设上限，按原约定累计毒伤；虚弱效果上限不应用到毒层。
- 上述5%/50%作为已确认的首版虚弱数值，后续可根据试玩调试。

## 已确认：状态生命周期

| 情况 | 规则 |
| --- | --- |
| 切换角色 | 生命、异常、结界与冷却绑定各自角色；切人不清除或转移 |
| 后台角色 | 存活时已有毒伤/瘴气伤害正常结算，毒层、结界与冷却继续计时；不接受新的场景攻击或区域影响 |
| 暂停、对话、暂停菜单 | 战斗计时停止，持续伤害、状态倒计时、结界时长和冷却一起暂停 |
| 过关或切换场景 | 保留生命、异常与剩余冷却；结界结束 |
| 角色死亡 | 结界消失，异常记录保留但停止计时与扣血；普通治疗不能复活 |
| 检查点重试 | 恢复检查点记录的生命、状态、道具、冷却、结界与关卡进度，相关记录一起还原 |
| 存档与读档 | 保存并还原各层状态剩余时间等记录；离线期间不计时、不扣血 |

- 场上角色死亡后，由存活队员接战；全队死亡则挑战失败。
- 保存、过关与普通回血不自动净化负面状态。
- 若使用复活能力，未被对应解除的异常重新生效；复活附带净化时，按其明确的净化能力处理。
- 重试时，道具消耗与收集物、已净化源头等关卡记录一起回退。

## 已确认：通用控制范围

| 控制类型 | 基本效果 |
| --- | --- |
| 硬直 | 短暂打断动作 |
| 击退 | 将目标沿水平方向推开 |
| 浮空 | 将目标打离地面，形成空中追击机会 |
| 减速 | 降低移动速度，保留攻击与技能操作 |
| 束缚 | 限制移动与跳跃，保留允许使用的攻击和技能 |
| 眩晕 | 暂时无法主动行动 |

- 六类作为首版控制范围，按招式附加效果配置。
- 具体行动限制、切人、叠加、抵抗与解除规则均按下文已确认内容执行。灵力/妖力抗性继续只减少对应伤害，不自动改变控制效果。

### 已确认：受控期间操作与动作打断

| 控制 | 动作与操作限制 |
| --- | --- |
| 硬直 | 打断当前动作，短暂禁止移动、攻击、技能、闪避与用药 |
| 击退 | 打断当前动作，被动水平移动；允许原地攻击、无位移技能与用药 |
| 浮空 | 打断当前动作，被动空中运动，期间无法主动操作 |
| 减速 | 不打断动作，仅降低移速，其他操作正常 |
| 束缚 | 禁止主动移动、跳跃、闪避，打断位移招式；保留原地攻击、无位移技能与用药 |
| 眩晕 | 打断当前动作，期间无法主动操作 |

- 切人作为队伍指令单独处理：切换冷却允许时，受控期间仍可切人。
- 控制保留在原角色身上，后台继续按自身时长结算，切人不解除控制。
- 受控期间继续正常承受伤害，不产生受击无敌。

### 已确认：控制叠加

| 情况 | 规则 |
| --- | --- |
| 同类硬直、束缚、眩晕 | 剩余时间取当前剩余时间与新效果时长中的较大值，不相加 |
| 不同类型控制同时存在 | 分别计时，操作限制同时生效；某种控制结束后，其他控制继续作用 |
| 多个减速来源 | 各自计时，当前只采用最强减速；最强效果到期后，仍存在的较弱效果接替 |
| 同一时刻多个击退或浮空 | 分别取同类中最强的位移效果，距离/高度不简单相加；后续独立命中仍可再次施加 |

- 虚弱的移速降低参与最强减速比较。最终移速 = 未受这些减速影响时的移速 ×（1 − 当前最强移速降低比例）。
- 例如虚弱降低30%移速、蛛网降低40%移速，最终降低40%；虚弱的攻击伤害降低仍保留。
- 控制效果的取舍不影响伤害，每次有效命中仍正常扣血。
- 每次新控制先按下述独立控制抗性计算，再应用叠加规则。

### 已确认：控制抗性与控制免疫

- 设置独立的控制抗性，与灵力抗性、妖力抗性分别配置，只影响六类控制。

| 项目 | 规则 |
| --- | --- |
| 硬直、束缚、眩晕、减速 | 实际持续时间 = 原时长 ×（1 − 控制抗性）；减速幅度保持原值 |
| 击退、浮空 | 按控制抗性减少击退距离、浮空高度 |
| 抗性来源 | 自身与衣物的控制抗性依次合并，综合上限80% |
| 特殊控制免疫 | 按类型独立配置，例如免疫浮空；伤害仍正常结算 |

- 综合控制抗性 = min（80%，1 −（1 − 自身控制抗性）×（1 − 衣物控制抗性））。例如30%综合控制抗性将2秒眩晕缩短至1.4秒。
- 每次新控制施加时计算抵抗，再按已确认的叠加规则处理。
- 连续受控仍逐次使用当前抗性，不自动获得额外免控。
- 控制免疫默认阻止新控制，解除已有控制需要明确的解控能力。
- 中毒、邪气虚弱、瘴气继续沿用各自规则，控制抗性不缩短或清除这些状态。

### 已确认：控制自然结束与主动解除

| 控制类型 | 自然结束条件 |
| --- | --- |
| 硬直、减速、束缚、眩晕 | 各自剩余时间归零 |
| 击退 | 本次强制位移结束 |
| 浮空 | 目标落地 |

- 解控技能/道具明确标注可解除的控制类型，一次清除对应类型的全部来源；其他控制继续存在。
- 能行动时可自行使用。硬直、浮空、眩晕期间，需要明确标注“受控可用”的解控能力，或由队友协助解除。
- 解除减速只处理普通减速；邪气虚弱继续按其净化规则处理。解毒/净化是否兼具解控效果，由能力明确标注。
- 明确依附绳索、法阵等源头的控制，可以通过破坏对应源头解除。
- 解除击退时停止强制位移；解除浮空时恢复操作，仍在空中则按正常空中动作与重力处理。
- 解控默认只移除控制，回血、免伤或免控作为额外能力配置；后续新控制仍正常判断。

| 数值边界 | 已确认，详见“数值边界” | 本体/结界三类常规减伤最高80%；虚弱每层降攻击伤害/移速各5%，最高各50%；生命在0至最大值间，计算保留小数、显示取整，无强制最低1点伤害 |
| 状态生命周期 | 已确认，详见“状态生命周期” | 切人绑定保留，后台已有状态继续；暂停/对话/离线停止计时；过关保留负面但结束结界；死亡停止异常；重试/读档还原对应记录与资源进度 |

### 其余范围与不应混淆的边界

- 破界当次命中不会伤害本体，其附带状态也被结界拦截；后续独立命中再判断本体。
- 灵力/妖力伤害免疫不自动变成毒、虚弱或瘴气免疫；对应状态免疫独立配置。
- 中毒层数没有上限，死亡只判断生命归零；中毒是否能施加仍按对应毒免疫等既有规则判断。
- 对自身净化不自动代表清除了区域源头；若源头仍在，按原来源触发间隔重新判断影响，净化不重置间隔。
- 普通非妖物/灵物攻击道具已确定为物理伤害；首版主体单一属性、附加效果独立结算已确认。邪气/瘴气沿用既定处理方式，首版不加入妖力临时压制。
- 首版六类控制及行动权限、动作打断、受控期间切人/后台计时、叠加、抵抗/免疫、自然结束与主动解除规则均已确认。
- 第1至第10项及本轮收尾规则均已确认；数值/内容配置列在上文，战斗代码已接入前三篇所需子集，完整机制继续按本方案扩展。
