# 动画关键节点参考：正篇与完结篇

版本：0.1 · 整理日期：2026-10-25 · 状态：供剧情设计审核的参考资料，不是游戏章节定稿。

## 范围与读法

正篇按官方第1～167集、完结篇第1～26集整理，共193集。特别篇沿用官方集号；不混入四部剧场版或《半妖的夜叉姬》。集数依据[日升正篇目录](https://www.sunrise-inc.co.jp/work/detail.php?cid=29)及[完结篇官方目录](https://www.sunrise-inc.co.jp/yasya-kanketsu/onair/index.html)。

下文分组仅供检索动画，不代表游戏阶段、章节数量或时长已经确认。“独立人物”对应本轮讨论的第三方人物，不增加游戏第三个竞争阵营。

“登场”包括首次介绍或关键正式活动；同行、受控、合作、背叛、退场另行说明。能力展示不一律视为首次习得，人物心理成长不直接等于战斗数值成长。回忆集标注播出位置，不把播出顺序当成历史时间。
