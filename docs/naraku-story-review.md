# 奈落线剧情章节 v1.0

版本：1.0 · 确认与保存日期：2026-10-26 · 状态：章节结构已整体审核通过，正式作为剧情基础设定的章节明细；逐篇任务与数值待细化，尚未接入游戏。

用户已确认双时间轴的10阶段、39篇主线与12条支线系列，以及对应的人物、成长和故事节点。奈主01沿用已确认的鬼蜘蛛受火伤、桔梗照顾、万妖吞噬与奈落诞生、伪装犬夜叉夺玉，再跨越旧时代至玉碎并开始收集的顺序。

本文纳入[剧情基础设定 v1.0](story-system-design.md)，作为奈落线正式章节明细，保留原编号与篇章内容。依据[动画关键节点参考](anime-story-milestones.md)及其中的官方剧情来源，继续遵守[四魂之玉系统v1.0](shikon-jewel-system-design.md)和[人物成长v1.0](character-growth-design.md)。

篇章数量用于组织事件，不代表关卡数、开发排期或通关时长。人物登场、加入关系与可操作资格分别审核；任务目标不预设成功，原作失玉、背叛和死亡不自动变成玩家必然结果。

双方共享同一批真实碎片。任何一方实际集齐立即确定胜负，不要求走满本稿。支线不得藏住唯一通关必需能力；含真实碎片的可选事件必须另配可达的替代夺取路径。暂停、对话、离线仍停止计时。

## 路线定位与来源标记

以奈落阵营为叙事核心：鬼蜘蛛前史与奈落诞生 → 旧日夺玉阴谋 → 五十年后玉碎与收集 → 交易与伪装 → 分身行动 → 内部裂痕 → 圣山重组 → 藏心与反叛 → 最终归玉。已确认10阶段、39个主线事件篇章、12条支线系列，独立编号“奈主01～奈主39”“奈支01～奈支12”。

上一版对照表中的主角修炼、现代生活及独立人物行动按需要列为敌情或世界事件；不要求奈落逐篇亲历、逐篇阻击。具体篇章名称与行动方向已确认，任务步骤与执行人物继续逐篇配置。

- 动画依据：动画存在相应的奈落或阵营行动。这里只确认故事依据，可玩任务仍属改编，不把动画结局锁成玩家必然结果。
- 用户指定主干＋动画前史重排：按用户修改确定第一篇主干，把动画较晚揭露的前史提前到奈落线开篇；演出和具体任务继续细化。
- 动画节点＋任务补写／游戏补写：动画只提供人物或背景，奈落任务方向属于已确认的游戏改编；具体流程仍需编写，不因此变为动画既有事实。
- 游戏结局改编：为已确认的奈落阵营胜利条件重新编排，不声称动画存在奈落胜利结局。

本线按阵营视角编排，不预设整条路线只能操作奈落本体，也不默认所有分身、佣兵或受控人物可操作。分身产生、临时合作、自愿效忠与强制控制须分别记录。操控名单和派遣表现另审。

## 阶段1：诞生与寻玉

目标：从鬼蜘蛛的前史开始，让玩家理解奈落如何诞生、为何执着桔梗与四魂之玉，再进入玉碎后的收集。

人物与阵营：鬼蜘蛛、桔梗、犬夜叉、诞生后的奈落为第一篇核心；跨越五十年后衔接戈薇带来的玉重现与破碎。不提前安排神乐、神无、白童子或白夜。

用户本轮指定的主干为受火伤、桔梗照顾、万妖吞噬、形成奈落、变身犬夜叉夺玉、等待玉碎与收集；封印、焚玉及五十年过渡用于衔接动画既有历史，具体对白、互动和演出仍待细化。

胜负与库存边界：旧日完整玉的抢夺属于前史，此时收集竞赛尚未开启，不以这段持有完整玉的剧情判定奈落胜利，也不让旧日玉重复进入当代库存。玉碎、正式争夺开启后，才按实际碎片份额记录与判定胜负。

### 同期敌情与世界事件

第一篇先呈现五十年前的前史，再接入正篇开场。玉碎后，结罗、兄弟争刀、雷兽及朔夜作为同期世界事件；必要消息按侦察逐步获得，不把这些事件全部改为奈落亲历。

## 逐篇细化与配置边界

1. 39篇主线与12条支线系列已整体通过；奈主01继续细化段落演出、对白与互动，奈主02的具体任务、持玉对象及份额按后续章节配置，不将已通过的整条路线继续标为待审核。
2. 已有动画行动如何变成实际可玩的追踪、潜入、护送、截击与战斗；具体人物名单未定。
3. 奈主29“白夜初行”、奈主33“冥道的试探”作为已确认篇章保留；继续细化补写任务与情报呈现，不按主角成长篇机械配对。
4. 哪些失玉、分身离心、人物生死属于固定背景，哪些允许按玩家表现分支；原作悲剧不是默认惩罚条件。
5. 12条支线系列已确认保留；真实碎片与替代路径逐项配置，不让奈落完成主角专属现代事件。
6. 奈主36沿实际碎片归属结算。终局攻坚、诱导及最后夺玉放在集齐之前或同场；已集齐就直接进入对应结局。
