## 一、已确认内容与本次提案范围

用户已确认：

- 普通小怪以连招压制、成群清理的爽快感为主；精英和首领承担更强的观察、应对要求。
- 小怪必须有《犬夜叉》的主题依据，保留作品中妖怪的辨识特征。
- 五种候选图鉴内容认可：尸舞鸦、蜘蛛头、最猛胜、极乐鸟、妖鼠群。
- 采用方案A：五种作为怪物总库，随对应剧情开放；本轮在独立开发验证场景检查全部五种。

本方案的战斗规则、美术动作、怪物组合、图鉴、奖励及方案A投放范围进入执行。数值为首版调试值，仍需要持续试玩平衡；当前验证结果见 `progress.md`。

## 二、系统层级与范围

| 层级 | 内容 | 体验目标 |
| --- | --- | --- |
| 普通小怪 | 五种已认可的妖怪 | 动作清楚、易于打断、适合连招和范围清理 |
| 精英 | 从现有种类选择适合的个体，增加一个专属机制；另行确认具体条目 | 数量少，观察到破绽后能快速解决 |
| 剧情特殊战 | 夺取四魂之玉的尸舞鸦等剧情个体 | 保留事件和能力的独特性 |
| 剧情首领 | 百足妖怪、逆发结罗 | 独立招式、清楚预警、反击窗口，与对应剧情关联 |

本轮制作建议优先完成五种普通小怪的素材、行为、图鉴及验证，再调整主线投放。精英和首领的详细招式另开设计确认，不作为本轮顺带扩展。

普通个体不持有四魂碎片，不继承剧情个体因四魂之玉获得的强化能力。

## 三、五种小怪图鉴与玩法

“普攻次数”统一指建议解锁阶段、正常主线成长的犬夜叉普通爪击基准伤害，不计连招末击、技能和强化；实际连招击杀通常更快。最终按两名角色分别试玩调整。

| 怪物 | 造型重点 | 主要攻击 | 战斗作用 | 耐久起点 |
| --- | --- | --- | --- | --- |
| 尸舞鸦 | 三眼、黑羽、尖喙，保留阴森的妖鸦轮廓 | 低空盘旋后直线俯冲 | 轻型空中突袭 | 2～3次普攻 |
| 蜘蛛头 | 人头、多条蜘蛛足、散乱长发，突出人兽结合的怪诞感 | 近身扑咬；部分个体远处吐丝 | 地面围攻与短暂干扰 | 2～3次普攻 |
| 最猛胜 | 蜂形身体、薄翼、明显腹部与毒针 | 悬停后向前突刺 | 极脆的蜂群骚扰 | 1～2次普攻 |
| 极乐鸟 | 人形上身与巨大鸟身结合，保留宽翼和利爪 | 降落扑击，落地后一次抓挠 | 相对耐打的空地近战 | 3～4次普攻 |
| 妖鼠群 | 深色鼠身、突出的门牙、细长尾巴，低矮而密集 | 地面接近，停顿后跃起扑咬 | 快速清群、突出范围攻击 | 1～2次普攻 |

### 01 尸舞鸦

- 主题依据：开篇与四魂之玉争夺相关的妖鸟，具有附身、操纵尸体的能力。
- 普通个体：盘旋 → 收翼预警 → 沿锁定方向俯冲 → 低空减速 → 重新升空。
- 受击反馈：被击中后短暂降低高度；犬夜叉可以跳击或在其俯冲后压制，戈薇可以提前射击。
- 批量出现的普通个体及其俯冲节奏属于游戏化改编；夺玉、附身能力保留给剧情特殊战。

依据：[读卖电视台开篇剧情](https://www.ytv.co.jp/inuyasha/story/2000_story/01.html)。

### 02 蜘蛛头

- 主题依据：动画“新月之谜”中成群出现、寄居死者头部的妖怪。
- 普通个体：贴地接近 → 抬足蓄势 → 扑咬 → 落地硬直。
- 吐丝个体：沿用同一种怪物素材，在攻击选择上采用吐丝；初次展示时不同时使用两种攻击，帮助玩家认招。
- 吐丝是玩法改编：单次命中短暂减速，不定身、不反复延长控制；丝团与蓄势均可被玩家攻击打断。
- 受击反馈：向后踉跄，允许持续连招；不获得普通攻击无法打断的状态。

依据：[读卖电视台第13话剧情](https://www.ytv.co.jp/inuyasha/story/2000_story/01.html)。

### 03 最猛胜

- 主题依据：奈落使用的毒虫，也是限制弥勒风穴的手段。
- 普通个体：低空悬停 → 尾部收拢蓄势 → 短距离突刺 → 减速调整位置。
- 普通攻击可快速击杀；范围技能可以清掉聚集的多只个体。
- 毒性玩法改编：当前首版每层持续3秒、每秒伤害2.5；重复刺中新增独立中毒层，不刷新旧层。参数继续试玩调试。
- 毒伤不产生额外受击硬直，不在死亡时爆毒；检查点清除状态。
- 飞行高度处于可跳击范围，避免只有戈薇能处理。

依据：[日升官方作品介绍](https://www.sunrise-world.net/titles/pickup_029.php)。

### 04 极乐鸟

- 主题依据：具有人的上半身的异形妖鸟，是妖狼族的天敌。
- 普通个体：空中观察 → 明显下压动作 → 降落扑击 → 落地抓挠 → 停顿后准备升空。
- 飞行路线与尸舞鸦区分：尸舞鸦快速掠过，极乐鸟落地后留下较长近战窗口。
- 体形更大、血量略高，但仍可被普通攻击打出硬直；保留普通怪可压制的规则。
- 不将巨型首领、持有碎片的强化个体作为普通小怪复制。

依据：[读卖电视台第36话剧情](https://www.ytv.co.jp/inuyasha/story/2000_story/02.html)。

### 05 妖鼠群

- 主题依据：动画中铁鼠操纵鼠群袭击村落；“妖鼠群”为游戏图鉴归类名。
- 普通个体：快速接近 → 短暂停顿 → 跃起扑咬 → 落地调整。
- 每只拥有独立的命中与击退反馈，允许一个攻击覆盖多只；不将整片鼠群做成持续接触伤害区域。
- 通过分批补入表现涌动感，避免同时堆积过多实体遮住脚下。
- 单只极脆，重点表现连续击飞、范围清理与鼠群溃散。

依据：[读卖电视台第91话剧情](https://www.ytv.co.jp/inuyasha/story/2000_story/05.html)。

## 四、普通怪共通战斗规则

### 攻击与公平性

- 身体接触不直接扣血；只有明确的攻击动作或投射物命中才造成伤害。
- 每次攻击包含预警、出手、收招三个阶段。预警先按0.5～0.8秒调试，收招按0.4～0.9秒调试。
- 普通攻击可以打断普通怪的蓄势和攻击动作，取消尚未发生的命中；已独立飞出的投射物按自身规则处理。
- 预警后段锁定方向或路线，出手后不瞬间转身、不持续追踪玩家。
- 普通怪不设置长期霸体、反复无敌或多阶段回血。
- 怪物在镜头内完成登场提示后才可攻击；屏外怪物不能发起新的攻击。
- 近战怪不会悬空追击或跨越无法到达的断崖；无法接近时调整位置，不隔着地形直接命中。

### 连招与角色差异

- 普攻命中产生可见硬直；连招末击、技能带来更强击退或打飞。
- 调整击退距离，确保连续普通攻击能接续，避免首击把目标推出后续攻击范围。
- 犬夜叉擅长近身打断、连击和群体压制；戈薇擅长提前处理空中与远处目标。
- 五种普通怪均可被两名角色独立击败，切换用于提高效率。
- 空中怪至少有低空攻击、受击下坠或落地窗口之一。

### 伤害与特殊状态

- 普通命中先以约主角最大生命的5%～8%作为调试预算，最猛胜包含其毒伤；以犬夜叉为基准后再检查戈薇承伤。
- 普通战的压力来自位置、组合和连续失误，避免单次小怪攻击造成大量损血。
- 玩家受击不提供无敌；同一次攻击采用命中记录防止按帧重复伤害，独立攻击分别结算，闪避仍可避伤。
- 减速各来源分别计时并取最强效果；中毒各层独立叠加，切人后仍作用于原角色。角色倒下清除其状态，重试按检查点恢复，神社检查点恢复时清除状态。

## 五、遭遇与怪物组合

- 同屏活跃普通怪先按3～5只调试，同一时间最多2只发起攻击，其余接近、调整位置或等待。
- 首次遭遇一种怪物时，先放1～2只，让玩家看清招式；之后再组成混合遭遇。
- 一场遭遇优先使用1～2种怪物，不一次叠加五种机制。
- 鼠群、蜂群使用短波次接续，在同屏数量限制内体现数量感。
- 默认从前方或清楚可见的区域登场；身后增援需有明确提示，且给予反应时间。
- 掉落、残骸与特效及时消退，保持敌人预警和地面边缘清楚。

开发验证组合：

| 组合 | 要验证的体验 |
| --- | --- |
| 蜘蛛头＋尸舞鸦 | 地面连招与空中切入能否清楚区分 |
| 蜘蛛头＋最猛胜 | 有控制干扰时仍能主动打断、快速清群 |
| 极乐鸟＋少量地面怪 | 较大目标落地时有足够的连招机会 |
| 妖鼠群连续小波次 | 范围清理爽快，脚下与预警保持可见 |

上述组合用于独立开发验证；主线只在剧情与场景合理时采用，不将验证组合自动视为主线投放方案。

## 六、美术、动作与音效

- 延续精细像素风，怪物各自保留原作辨识结构；与主角的像素密度、光照和画面比例一致。
- 各种怪物用轮廓、体形、运动方式区分，不能只依靠换色辨认。
- 每种具备：待机/盘旋、移动、攻击预警、攻击、收招、受击、死亡；按行为增加吐丝、落地等必要动作。
- 原作造型转为横版游戏时，调整遮挡和肢体展开角度，保证攻击方向可读。
- 保留诡异感，死亡表现以击退、妖气消散为主，不用大块特效盖住其他怪物。
- 命中使用短促停顿、受击闪白、音效与粒子反馈；蜂翼、鸦鸣、蛛足和鼠群声用于辅助辨认。
- 预警同时依靠姿态、声音和少量提示，避免只能靠颜色识别。

## 七、图鉴、奖励与存档

- 首次击败普通个体后解锁完整条目：名称、形象、背景简述、出没场景、攻击方式、应对提示。
- 未解锁条目只显示未知状态，避免提前透露后续剧情信息。
- 图鉴背景与玩法说明分开呈现，方便识别原作设定与游戏规则。
- 普通怪提供已有的经验和强化材料；本轮不增加装备、稀有词条等新养成系统。
- 四魂碎片保留为剧情或指定挑战奖励，普通怪不随机掉落碎片。
- 保存图鉴解锁状态；旧存档缺少相应数据时以未解锁状态补齐，角色与关卡进度保留。

## 八、与第一期四关的衔接：方案A已确认

当前第一期仍为开篇至逆发结罗，按既定方案保留关键事件顺序。用户选择按剧情逐步开放。

### 按剧情逐步开放

- 五种作为全游戏的普通怪总库，本轮可在独立开发验证场景检查全部素材与行为，无需新增正式游戏模式。
- 开篇主线使用与事件相关的尸舞鸦；蜘蛛头、最猛胜、极乐鸟、铁鼠鼠群留给相应后续章节。
- 第一关重点为穿越、解封、操作教学和百足妖怪战；第二关承担妖鸦与碎玉事件；第三、四关用发丝机关、平台路线和结罗战组织节奏。
- 接受开篇普通怪种类较少，减少重复清怪波次，避免用单一妖鸦填满现有所有遭遇点。
- 开篇若需要补足其他地面敌人，必须另行讨论有剧情依据的补充条目。

## 九、制作顺序

1. 按已确认的A投放范围执行五种普通怪的造型、动作与攻击规则。
2. 制作五种怪物的横版造型稿与实际尺寸对比，检查轮廓和作品辨识度。
3. 完成必要动作素材，并检查预警、命中时机、受击和死亡衔接。
4. 接入共通行为、各物种攻击、群体攻击调度和异常状态。
5. 在开发验证场景分别检查单只、小群、混合战斗，使用犬夜叉和戈薇各自验证。
6. 接入图鉴、奖励和旧存档兼容，再按确认的范围调整主线遭遇。
7. 完成首轮实机调参，记录验证结果；再讨论精英和首领的详细设计。

## 十、验收标准

- 五种怪物的外形与行为能清楚区分，保留已认可的《犬夜叉》主题依据。
- 普通怪可打断、可连招、可范围清理；两名角色都能独立处理全部普通怪。
- 预警与实际命中范围一致，出手后不突然转向；屏外敌人不发起攻击。
- 同屏遭遇保持可读性，不出现多个控制效果叠加导致无法操作的情况。
- 五种怪物各自的攻击、受击、死亡、奖励与图鉴解锁完整可用。
- 击杀奖励只结算一次；攻击被打断、目标死亡、玩家切换或重试后无残留伤害判定。
- 图鉴可在刷新后恢复，旧存档仍可继续；主线投放符合已确认的方案A。
