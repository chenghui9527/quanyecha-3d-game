# 犬夜叉动作与特效首版

更新：2026-10-23。用户确认基础攻击加入上挑、空中追打和下砸，并要求先制作犬夜叉的攻击动作与技能特效。飞刃血爪替换疾风爪袭后，最新确认散魂铁爪采用A方案斜向横撕，并增加砸地效果。数值、键位和取消窗口均是首版调试值。戈薇新技能、双人合击和后续武器技能仍待讨论。

## 操作与招式

| 输入 | 动作 | 表现与用途 |
| --- | --- | --- |
| J，可按住 | 横爪 → 返爪 → 横扫 | 三种起手、挥爪方向和音色；前两击小击退，末击更强击退 |
| 地面 S / ↓ ＋ J | 上挑 | 低身起手，向上划出三道爪痕；普通怪浮空，首领不浮空 |
| 空中 J | 空中追爪 / 返爪 | 两次追打交替，前两次空中攻击短暂调整纵向速度，不能靠按住J无限滞空 |
| 空中 S / ↓ ＋ J | 坠地爪击 | 收身起手、快速下降、纵向拖尾；落地冲击环、扬尘及短暂收招 |
| U | 散魂铁爪 | 蓄爪、斜向横撕、低身收势；仅三道金白月牙弧刃以实际刃面接触敌人，落点伴随贴地冲击环、碎石和扬尘；冷却5.5秒 |
| I | 飞刃血爪 | 取血、蓄势、挥爪甩出弯月血刃、收势；五道深红飞刃以不等间隔错落连发，刃身和轨迹统一朝前，带亮色锋缘、红色拖尾和命中碎光；冷却8秒 |

上挑后可以跳跃取消收招，接空中追打和下砸；技能可在普攻收招窗口接入。闪避和切人会终止尚未发生的攻击判定，已消耗的技能冷却保留。普攻与方向派生使用约200毫秒的输入缓冲，命中停顿期间也能记录攻击输入。空格、W和↑继续用于跳跃。

## 判定与演出

- 每个动作都有起手、有效攻击和收招时段，挥爪前不提前扣血。
- 每个动作对同一目标只造成一次伤害；下砸下降与落地共用命中记录。
- 攻击朝向在动作期间锁定。飞刃血爪为站定甩出的远程技能，血刃离手后自行飞行。
- 上挑使用普通怪浮空物理，取消其攻击；落地后恢复原有行为。空中追打可以续接其浮空，下砸可将空中目标打落。
- 下砸尊重实际平台高度，在落点绘制冲击效果；下砸缺少地面时仍会落入断崖并按原规则处理。
- 攻击继续可以破坏蛛丝和结罗的发丝结点；首领沿用原受击规则。
- 普攻伤害倍率1 / 1 / 1.4，上挑0.9，空中追打1 / 1.15，下砸1.6，散魂铁爪2.7，飞刃血爪2.3。主动技能仍受现有技能强化影响。

## 散魂铁爪：斜向横撕与砸地

- 动画画面参考：[初遇尸舞鸦时的散魂铁爪片段](https://www.bilibili.com/video/BV1Mj41187dS/?t=4)，本轮实看约3～5秒处的出爪镜头，第4秒可见细长、平滑的金色弧形爪光随挥手扫过。本作据此优化线条与短促残像；三刃数量、站地斜撕、砸地演出与数值均为已确认的游戏化设计。
- 用户确认A方案：蓄爪时略向后收肩，向前斜向挥爪，再压低身体收势。沿用现有战斗图中的蓄爪、伸爪、低身横扫和回收姿势，配合轻微身体倾斜；出手至有效攻击结束站定发力。
- 仅保留三道明显向前弯出的月牙弧刃：改用平滑、较细的浅金色刃面和白色锋缘，凹侧保持空心；保留内、中、外三条轨迹，每次独立确定长短、间距、控制点和宽度，在约0.04秒内先后出爪。随机形状在这次演出中固定，避免逐帧闪烁。
- 对照动画收敛厚重的金属色层、锯齿内缘与剥离碎块，改为细金白爪光迅速扫开、尾部紧接着收走。每刃约0.055秒展开，约0.075秒后开始收尾，约0.195秒内消失；少量短速度笔触随挥爪方向拖开，保持三道主体清晰。
- 绘制与命中共用弧刃轮廓，只对当前已展开的实体刃面进行接触判定，替换旧的前方矩形范围；空心区域、角色身周和装饰光晕均不产生伤害。左右朝向镜像一致，敌人、细小蛛丝和发丝结点使用同样的接触规则。“显示碰撞范围”同步展示实际弧刃轮廓。
- 挥爪开始约0.075秒后，在中间弧刃末端对应的地面出现砸地冲击：贴地双环、短促亮光、临时地表裂纹、碎石、低矮扬尘和金色碎光，配合低频落点音与轻微震屏。碎石运动和形状使用本次固定随机种子。
- 砸地落点必须处于同高度的实际支撑面，尊重高台高度；空中释放或落点位于断崖时只表现斜向挥爪。闪避、受击、切人在落点触发前中断动作，会停止尚未发生的砸地效果。
- 命中目标时显示三道缩小的短弧形抓痕，避免叠出额外大刃的观感；伤害在挥爪有效阶段由实际弧刃接触触发，对同一目标只结算一次。砸地为视觉与声音反馈，伤害倍率2.7、最大近战距离约175像素、起手0.14秒、动作总长0.56秒和冷却5.5秒沿用现值。
- 三道命中痕采用短白切线与微微错开的暗缝，按实际怪物图像大小缩放，并裁切到当前姿势的不透明轮廓内；切痕绑定命中目标，随移动、受击与倒地姿势更新，持续约0.46秒后淡出。目标亮闪约0.055秒，再接原有短暂停顿与击退；少量细碎速度笔触沿挥爪方向飞散。命中表现是本作对“撕开”感觉的转译，不是对参考镜头逐帧复刻；挥爪与命中保留短促撕裂音，砸地沿用低频反馈。
- 验证场“出手定格”调整到挥爪开始约0.09秒后，同时展示三道爪光与初始砸地冲击。

## 飞刃血爪：原作依据与本作演出

[读卖电视台官方第4话剧情](https://www.ytv.co.jp/inuyasha/story/2000_story/01.html)明确将飞刃血爪称为血刃，并描述犬夜叉以其切断结罗的发丝。关于自身血液注入妖力后化作弯刃、用于远程奇袭的细节，参考[招式资料](https://inuyasha.fandom.com/wiki/Hijin_Kess%C5%8D)，该条目引用《犬夜叉 奥义皆传》第31页；本项目未直接核验该纸本页。

- 角色新增四帧动作：指尖取血 → 拧身蓄势 → 向前甩出 → 收势。取血仅表现少量指尖血色。
- 血刃采用深红实体轮廓、绯红刃身、浅亮锋缘与短时残迹。每道血刃在发射时独立随机确定弯曲程度，形成较平缓和更深弯的月牙；轮廓、刃身与锋缘同步变化，飞行期间保持该形状，不逐帧抖动。出手时只保留手边的短血痕，主体随弹体前进；命中产生交叉切痕和碎光。
- 首版游戏化参数：起手0.20秒、动作总长0.64秒，五刃在随后约0.17～0.22秒内以不等间隔依次射出；出手高度按不规则顺序错开，每道独立增加上下各12像素的随机偏移（原为各4像素），前后位置和时间保留小幅扰动。高度在发射时确定，飞行期间不抖动。每道血刃速度统一为720像素/秒，垂直速度为0，统一朝本次出招锁定的左方或右方直线前进，不形成扇形散射。最大飞行距离600像素，8秒冷却；本轮沿用冷却制，不增加扣血或受伤前置条件。刃数、射程、伤害和冷却均不是原作数值。
- 可以穿过多个目标、切断蛛丝和攻击发丝结点；同次释放共用命中记录，同一目标最多承受一次完整技能伤害。飞行轨迹使用沿途判定，避免快速血刃漏过细小目标，并保留触地消散规则。
- 闪避、受击或切人会中断尚未发射的血刃，冷却保留；已射出的血刃在切人后继续飞行，伤害在发射时确定。技能不提供旧突进技能的位移或无敌。
- U键散魂铁爪的金白斜向爪痕与砸地演出见上一节，近战范围、伤害和冷却沿用现值。

- 人物图：`assets/characters/inuyasha-combat.png`，16个姿势。待机、奔跑与普通跳跃保留原素材。
- 飞刃血爪人物图：`assets/characters/inuyasha-blood-claws.png`，四姿势透明图，独立于原战斗图，生成提示词见 [血爪动作提示词](inuyasha-blood-claws-art-prompt.md)。

- 直接打开 `dist/monster-lab.html`，默认进入犬夜叉动作练习；切换怪物组合或数量立即生效。点击单招或“连招演示”时保留当前物种、数量与组合，将所选目标设为耐打且不主动进攻，方便观察身体上的命中细节；点击“开始 / 重置”恢复所选遭遇的正常血量和行为。“动作练习”始终使用耐打目标。键盘自由出招不替换当前目标，本页不读写主线存档。
- “慢动作×0.25”放慢练习场；“出手定格”在每次出手后暂停，Esc继续。下砸落地也可单独定格。
- 主线 `dist/index.html` 同时接入这些动作。
