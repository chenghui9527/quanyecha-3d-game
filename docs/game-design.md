# 犬夜叉：四魂初旅 — 游戏基础设定 v1.0

版本：1.0 · 确认与更新日期：2026-10-26 · 状态：用户已将剧情设计确认为游戏基础设定；主角线前三篇试玩基本通过，后续按本总纲与四项基础规范继续制作

## 基础设定体系

用户在确认双阵营剧情章节、体验主角线前三篇后，反馈“试玩基本ok”，并明确要求将剧情设计纳入游戏基础设定。本文件由总设计v0.8升级为基础设定总纲v1.0，统一以下四项规范。

| 基础规范 | 约束范围 | 正式依据 |
| --- | --- | --- |
| 基础战斗 | 伤害、防御、结界、异常、控制、死亡与生命周期 | [基础战斗 v1.0](combat-system-design.md) |
| 人物成长 | 剧情晋升、生命与对应力量、人物及技能／武器／装备解锁 | [人物成长基础设定 v1.0](character-growth-design.md) |
| 四魂之玉 | 世界唯一、份额守恒、实际归属、情报、争夺、AI与集齐胜负 | [四魂之玉系统基础设定 v1.0](shikon-jewel-system-design.md) |
| 剧情 | 两套阵营路线、10阶段、主支线、人物与成长节点及章节衔接 | [剧情基础设定 v1.0](story-system-design.md)及两线章节明细 |

后续人物、任务、关卡、成长、碎片、AI、界面和存档以四项规范为共同依据，逐篇按正式编号补充内容。已确认的规则与故事结构作为制作基础，具体数值、美术、任务步骤及未制作内容继续细化；历史草案用于追溯，已确认的游戏规则用于处理动画素材的改编衔接。

## 已确定的方向

| 项目 | 决定 |
| --- | --- |
| 首发平台 | Web 网页；第一期优先电脑键盘操作 |
| 游戏类型 | 单机横版 2D 剧情动作闯关 |
| 操作 | 亲手走位、跳跃、攻击、闪避、释放技能 |
| 美术 | 三到四头身的精细像素风，人物帅气、动作舒展 |
| 剧情 | 犬夜叉与奈落两套阵营剧情，围绕同一世界事件争夺碎片，行动与结果可以不同 |
| 剧情章节 | 10个同期阶段；主角线51篇主线、22条支线，奈落线39篇主线、12条支线，保留各自编号与剧情顺序 |
| 阵营 | 玩家选择犬夜叉阵营或奈落阵营，敌对阵营由AI控制 |
| 队伍 | 所选阵营编队，场上操作一人，战斗中随时切换；具体人物名单待配置 |
| 难度 | 适中动作：普通战斗爽快，精英和首领需要观察与应对 |
| 人物收集 | 人物按剧情、支线与挑战解锁；奈落阵营具体加入条件待配置 |
| 四魂之玉 | 总份额固定，双方争夺同一批碎片，按占完整玉的份额计算进度；任意一方集齐则胜利，另一方失败 |
| 信息与第三方视角 | 双方收集进度公开，具体行动通过剧情和侦察揭示；一期第三方视角只做进度比对面板 |
| 养成 | 无经验与技能点；指定任务/剧情提升人物大等级，成长生命值及按人物设定对应的妖力或灵力；技能、武器、装备按剧情或特定人物条件解锁 |
| 第一期规模 | 当前可玩主角线犬主01～03，共六幕；奈落可玩路线及一期最终覆盖待细化 |

基础规则和内容结构以本总纲所列四项正式规范为共同依据，章节明细按主角线与奈落线的原编号引用。具体关卡、尚未配置的数值与键位继续通过制作和试玩调整。

## 剧情基础设定 v1.0

用户于2026-10-26通过两条剧情时间轴的整体审核，正式确认10个同期阶段、90篇主线与34条支线系列；阶段、篇章顺序、名称、主支线、人物关系与成长故事节点，以及奈落线游戏补写方向纳入[剧情基础设定 v1.0](story-system-design.md)。

| 路线 | 主线与支线 | 正式章节明细 |
| --- | --- | --- |
| 主角线 | 犬主01～犬主51，犬支01～犬支22 | [主角线剧情章节 v1.0](protagonist-story-review.md) |
| 奈落线 | 奈主01～奈主39，奈支01～奈支12 | [奈落线剧情章节 v1.0](naraku-story-review.md) |

奈主01保留鬼蜘蛛受火伤、桔梗照顾、万妖吞噬、奈落诞生与伪装夺玉，再跨越五十年接续玉碎和收集。两线按同期世界事件对照，不要求逐篇镜像；前史完整玉不触发胜负，正式争夺后任意一方集齐立即进入对应结局，不要求走满全部篇章。

主角线犬主01～03已实现为六幕，任务、碎片与成长首版配置见[前三篇可玩首版](opening-three-chapters.md)。其余篇章继续细化任务、关卡、对白、操作资格、碎片与成长；篇章数量不等于关卡数量或通关时长，一期最终覆盖待定，旧合并对照仅作历史资料。

本次基础设定确认同时记录前三篇的用户反馈：基本可玩流程已通过试玩，作为后续章节的制作参照。份额、生命、伤害、技能时长、首领节奏和专属美术仍可调试，奈落可玩路线与其余篇章按既定结构继续制作。

## 四魂之玉系统基础设定 v1.0

用户已完成整体审核，并于2026-10-25确认双阵营剧情方向、一期比对面板与四魂之玉系统八项核心规则。完整规则见[四魂之玉系统基础设定 v1.0](shikon-jewel-system-design.md)。

| 模块 | 基础规则 |
| --- | --- |
| 唯一性与进度 | 世界中只有一颗玉，碎片总份额固定；归属唯一，按份额计算进度，重玩不重复产生碎片，合并或拆分不改变总量 |
| 情报 | 真实归属与玩家已知情报分开；公开收集比例不自动揭示持玉人物、位置或计划 |
| 双阵营剧情 | 同一份碎片承接双方不同任务、对话与行动，结果统一改变实际归属 |
| 获得与争夺 | 战斗、探索、任务、拦截及特定交换或交付取得碎片；按实际携带与任务范围争夺，普通失败不掉落全部成果，被夺后有夺回路径 |
| 碎片力量 | 按人物与剧情配置有上限的暂时强化或战斗机制，不替代永久成长；主动使用资格与效果待定 |
| 净化与污染 | 明确状态，由能力或剧情转换；影响使用、战斗或剧情，不改变份额和集齐判定，不增设持续污染数值或维护消耗 |
| AI推进 | 由具体行动及指定剧情阶段或世界事件结算，可被干预也可失败；不按现实时间自动涨进度，暂停/对话/离线停止计时 |
| 胜负 | 玉破碎且争夺正式开始后启用判定；集齐即确定胜负并进入对应结局，不附加许愿、仪式或守时条件；章节完成单独结算 |
| 一期面板 | 展示双方及尚未归属双方的比例；不开放完整独立观战，不自动公开隐藏行动 |

实现状态：前三篇已接入总份额固定、两份玩家碎片、两次敌方事件收集、已知情报、集齐判定和比对面板；阵营选择已接入，奈落目前仅提供筹备中的路线预览。奈落可玩路线、动态失玉与夺回、碎片强化及净化污染继续配置和实现。

## 游戏基础战斗设计 v1.0

确认与保存日期：2026-10-25。完整规范见 [游戏基础设计 v1.0：全局战斗机制](combat-system-design.md)，下表为总览摘要。后续角色、怪物、技能、装备、道具、关卡与存档逻辑以该规范为共同基础。

| 模块 | 基础规则 |
| --- | --- |
| 伤害来源与属性 | 普攻为物理；技能按妖力/灵力属性；普通攻击道具为物理，妖物/灵物为对应属性。主体单一属性，附加效果独立 |
| 原始伤害 | 角色攻击使用对应输出属性乘招式/技能倍率；道具使用自身威力，状态伤害由来源配置 |
| 本体防御 | 衣物与自身对应减伤依次计算，物理/妖力/灵力综合减伤常规上限80%；特殊伤害免疫独立 |
| 结界 | 防御技能或道具开启，独立耐久和防御，同一目标一个有效结界；破界当次不溢出到本体；具体生命周期按完整规范 |
| 中毒 | 每秒按各层毒性合计掉血，各层独立到期，层数无上限；自然消退、解毒药或解毒技能处理，特殊人物可毒免疫 |
| 邪气 | 一次性妖力伤害并叠加虚弱；每层降低攻击伤害/移速各5%，最高各50%；普通灵力净化或对应道具清除 |
| 瘴气 | 直接与持续妖力伤害，持续状态只保留最强效果至净化；特殊灵力、高等级灵力或携带特殊灵力的道具净化，特殊人物可瘴气免疫 |
| 闪避与免疫 | 保留闪避无敌，不设受击无敌；伤害免疫、状态免疫、控制免疫分别判断，不加入妖力临时压制 |
| 控制 | 硬直、击退、浮空、减速、束缚、眩晕六类；行动限制、叠加、抗性、免疫与解除按完整规范，独立控制抗性常规上限80% |
| 治疗与关卡准备 | 危险区域不可绕行，提前收集对应道具或安排有对应能力的治疗角色；角色净化与区域源头净化分别配置 |
| 死亡与结算 | 只在生命归零时死亡；按已确认同刻事件顺序结算，死亡和收益只处理一次；计算保留小数，显示取整 |
| 生命周期 | 切人保留各自状态，后台已有状态继续；暂停/对话/离线停止计时；过关保留异常但结束结界；重试/读档统一恢复对应记录与资源进度 |

实现状态：已接入前三篇所需的物理／妖力／灵力伤害分类、减伤计算、自用结界、不提供受击无敌、同次弹幕去重、中毒独立叠加和最强减速。邪气／瘴气、完整六类控制、净化与道具能力继续实现；具体范围见前三篇配置文档。

## 当前可玩内容与目标

主角线第一阶段“玉碎与启程”中的犬主01～03已实现，共六幕。可操作人物为犬夜叉和戈薇，内容覆盖相遇、玉碎、结罗与父亲墓地中的铁碎牙。任务与参数详见[前三篇可玩首版](opening-three-chapters.md)。实际人工通关时长待试玩测量，不沿用旧四关原型的20～30分钟目标作为本版承诺。

| 犬主01 封印与玉碎 | 碎玉之光 | 尸舞鸦、玉碎、互动取得村外碎片与寻玉之约 |

剧情节点使用正式章节明细，内部对白、场景、交互、战斗表现和首版参数为本轮游戏化配置。铁碎牙在第三篇开放，不提前配置风之伤。奈落可玩路线尚未接入，敌方目前通过指定世界事件取得其对应的真实份额。

## 战斗与切换

- 全局机制以[基础战斗设计 v1.0](combat-system-design.md)为准；前三篇已接入所需子集，完整状态、控制和道具配置继续实现。
- 基础动作：左右移动、跳跃、普通攻击、空中攻击、闪避、主动技能。
- 犬夜叉：近战爪击连招、上挑追打和空中压制，并以飞刃血爪截击远处目标，强调力量与速度。
- 戈薇：弓箭、蓄力攻击与后撤，强调射程、出手节奏与目标选择。
- 双人加入队伍后，按 1 / 2 直接切换，或按一个按键循环切换。
- 切换不消耗资源，成功切换后共用1秒冷却；新角色在当前位置登场。键盘、卡片点击与触控共用限制，暂停／对话停止计时，人物倒下时仍由存活同伴接战。
- 每名角色保留独立生命与技能冷却；一人倒下后其他队员仍可继续。
- 普通敌人攻击可被合理打断；精英敌人有特殊能力；首领攻击有清楚的预警和反击机会。
- 首领前设检查点，失败后快速重试。普通关卡节奏爽快，整体按正常主线成长安排难度。

## 人物成长基础设定 v1.0

用户已完成整体审核，并于2026-10-25确认作为基础设定。完整规则见[人物成长基础设定 v1.0：剧情与任务驱动](character-growth-design.md)，后续人物、剧情、任务、技能、武器、装备及成长存档以该规范为共同依据。

- 主线在原作对应节点解锁角色，解锁后即可使用。
- 额外角色的支线、挑战解锁随后续章节扩展；现有原型先完成双人获得与切换闭环，奈落阵营具体人物与加入条件待配置。
- 删除人物经验与技能点；人物等级改为大等级，只能由指定任务完成或指定剧情推进提升。
- 人物阶段成长提升生命值，以及按人物设定和剧情节点对应的妖力或灵力；犬夜叉对应妖力，戈薇对应灵力。其他战斗属性不因大等级自动增长；具体阶段、数值继续配置。现有力量强度与新增的可消耗能量储量分开，储量容量、消耗、恢复及成长关系待配置。
- 技能、武器、装备按各自剧情节点或特定人物的授予条件解锁，不由普通等级或资源强化自动获得。
- 成长事件奖励只结算一次，重复刷怪或重玩不重复提升人物阶段。
- 角色档案记录人物阶段、生命、适用的妖力/灵力与内容解锁状态；多角色阶段是否共享及伙伴加入配置待讨论。

实现状态：经验、普通等级、等级攻击加成和精华技能强化已移除；前三篇按指定事件提升人物阶段、生命上限与对应力量，并解锁铁碎牙。每人阶段独立记录，后续配置继续扩展。

## 美术与界面

- 人物三到四头身，保留犬夜叉的白发、犬耳、红衣，戈薇的长发、校服、弓箭等辨识特征。
- 像素边缘清晰；站立、奔跑、跳跃、攻击、受击的动作轮廓清楚。
- 场景使用有前后层次的和风森林、村落、神社，以飘叶、薄雾和光线营造气氛。
- 技能特效强调打击感，同时保证敌人的攻击预警清楚可见。
- 游戏内界面已按确认的合成紧凑版实现：左上队伍、右下行动、上中首领、右上目标与工具、左下四魂；暂停统一为六页签旅途手记（含独立公用道具），对话与触屏同步适配。生命、状态、技能冷却和当前目标读取实际数据，见[游戏内界面 v1.0](game-interface-design.md)。
- 用户明确妖力／灵力条表示技能可消耗的能量储量，现按新要求为两名已加入人物默认显示100／100并渲染填充。该值为界面展示默认值，正式容量、消耗与恢复规则继续配置；不把力量强度当作储量。
- 页面包括标题、阵营选择、篇章选择、战斗、暂停、人物成长、四魂进度比对、结算与结局；新旅程先选择阵营，一条存档固定阵营，继续和章节重玩沿用原路线。当前仅犬夜叉前三篇可开始，奈落选择可预览并明确标注筹备中，具体流程见[阵营选择](faction-selection-design.md)。

## 本地存档

浏览器本地保存章节解锁、角色获得、人物大等级、已完成成长事件、技能/武器/装备解锁与检查点。刷新后可以继续；提供导出、导入存档，避免浏览器数据清理造成唯一进度丢失。当前存档为version 2，兼容旧版；成长、内容解锁、碎片与事件随对应检查点一致恢复。

当前固定主角阵营，已记录碎片归属、已知情报、成长和世界事件；双方份额与集齐胜负由唯一归属推导。后续继续配置其他阵营、碎片状态与动态争夺，重试和读档仍须保持完整记录一致。

## 现有原型制作顺序

1. 保存设计与可接续的进度记录。
2. 制作精细像素风视觉素材和实机画面方向。
3. 实现角色移动、跳跃、战斗和双人切换。
4. 接入当前三篇六幕、剧情、检查点与首领，继续按后续篇章扩展。
5. 完成收集、成长、存档、音效和界面。
6. 实际浏览器试玩、修复问题，记录验证证据与剩余限制。

## 现有原型完成标准

- 能从标题页开始完成三篇六幕，并明确区分本批内容结束与整玉集齐胜负。
- 两名角色可解锁、切换，攻击方式与技能不同。
- 移动、跳跃、攻击、闪避、技能与首领预警均可实际操作。
- 成长有实际效果，进度可在刷新后恢复，关卡失败可从检查点重试。
- 页面视觉符合三到四头身精细像素方向，核心界面可正常使用。
- 完成自动化逻辑检查及浏览器实际操作检查；明确记录仍未验证的项目。

双阵营版本按已确认的剧情章节继续配置具体任务与验收内容，并遵守四魂之玉基础设定；以上原型标准不表示双阵营系统已完成。

## 接续规则

每完成一个制作阶段更新 `docs/progress.md`，记录完成内容、验证结果、启动方式及下一步。额度或运行中断时，以这些文件与实际代码为接续依据。自动续跑由运行环境控制，不能把等待本身视为目标完成。
