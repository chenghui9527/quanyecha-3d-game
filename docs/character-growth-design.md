# 人物成长基础设定 v1.0：剧情与任务驱动

版本：1.0 · 确认与保存日期：2026-10-25 · 状态：用户已完成整体审核并确认，正式作为基础设定；前三篇已接入剧情成长与铁碎牙解锁，后续阶段、数值与内容继续配置。

## 设计地位与范围

本文件与[游戏基础战斗设计](combat-system-design.md)、[四魂之玉系统基础设定](shikon-jewel-system-design.md)、[剧情基础设定](story-system-design.md)共同构成[游戏基础设定总纲v1.0](game-design.md)下的四项基础规范。后续人物、剧情、任务、技能、武器、装备、成长界面及存档设计与实现，以本文件的成长规则为依据。

本版本完整保存用户审核通过的成长结构、晋升条件、属性范围、内容解锁及进度记录规则。尚未确定的阶段名称、数值和具体内容继续列于“待配置与细化”，不因本次确认为已定配置。

剧情章节补充（2026-10-26）：[剧情基础设定 v1.0](story-system-design.md)及两线章节已通过整体审核。人物加入、武器与能力变化等故事节点作为后续配置依据；各节点对应的大等级、属性数值、受益人物、操作资格及具体奖励继续逐篇填写，不把剧情的10个阶段直接视作10个人物大等级。

本作定位为单机剧情动作游戏。本文件只规定人物成长、技能及武器装备的获得条件，不展开角色操作、招式效果、战斗流派或其他游戏模式。

原有经验升级、技能点及投入资源升级技能的方案由本文件替代。现有代码已移除经验、普通等级、等级攻击加成与精华强化，按已完成故事节点兼容旧版存档；当前成长配置限于[主角线前三篇](opening-three-chapters.md)。

## 已确定的成长结构

| 项目 | 规则 |
| --- | --- |
| 人物经验 | 删除；击杀、通关和重复刷怪不再积累人物经验 |
| 人物等级 | 改为少量、明确的大等级，表示人物的剧情成长阶段 |
| 大等级提升 | 只能由指定任务完成或指定剧情推进触发，不由战斗次数或材料积累触发 |
| 人物属性成长 | 生命值，以及按人物设定和剧情节点提升的妖力或灵力；生命成长配置为生命上限的提升 |
| 技能点 | 删除，不进行技能点获得、分配或重置 |
| 技能获得 | 按对应剧情节点或特定人物的授予条件解锁 |
| 武器与装备获得 | 同样按对应剧情节点或特定人物的授予条件解锁 |

大等级提升与内容解锁分别配置。一段剧情可以同时提供两类奖励，也可以只提供其中一类；达到大等级本身不自动授予未满足剧情/人物条件的技能、武器或装备。

## 大等级与属性

- 大等级数量、名称、各角色适用阶段及晋升任务尚未确定，不套用原型的1至20级经验曲线。
- 每个阶段按对应人物配置生命上限，以及适用的妖力或灵力数值，不设置阶段内经验条、修炼进度条或可反复积累的小等级。
- 妖力或灵力的成长类型由具体人物设定决定，提升节点由指定剧情或任务决定，不统一要求所有人物成长灵力，也不默认两项力量同时提高。
- 当前两名角色的成长方向：犬夜叉提升生命上限与妖力；戈薇提升生命上限与灵力。其他人物的力量类型、成长节点与增幅逐一配置。
- 每个成长节点分别配置提升项目和幅度，不要求所有人物同步成长，也不要求每次所有成长属性同时提高；不设置玩家手动分配属性点。
- 物理攻击力、防御、抗性、移动速度等不因人物大等级自动增长。它们仍可作为已有战斗规则中的配置属性存在，具体取值按对应内容另行配置。
- 界面确认补充（2026-10-28）：新增妖力／灵力条明确表示技能可消耗的能量储量，与现有`power`力量强度分开。当前成长配置继续作用于力量强度；储量容量、消耗、恢复及成长是否提高容量另行配置。界面已预留条并显示`— / —`，尚未启用消耗机制，见[游戏内界面](game-interface-design.md)。
- 生命上限提高后是否同时恢复当前生命，以及灵力提升与特殊净化资格的具体对应关系，待后续配置；不因本次成长设计默认获得回血或异常解除效果。

## 剧情与任务奖励

- 每项晋升明确记录触发剧情或任务、前置条件、适用人物、目标大等级、生命上限及适用的妖力/灵力配置；各节点明确实际提升的项目与数值。
- 仅被配置为晋升条件的指定任务或剧情触发大等级提升；普通支线和普通通关不默认晋升。
- 指定成长事件的奖励只结算一次，重复游玩同一内容不重复提高大等级或重复获得永久解锁。
- 正常主线中必须取得的成长，应配置在可达的剧情或任务节点；特定任务是否为可选内容逐项确定。
- 多角色的大等级是否独立记录、哪些晋升事件作用全队，以及新伙伴的初始阶段，仍待确定，不沿用旧方案的经验共享或等级追赶规则。

## 成长事件与进度记录

| 配置项 | 内容 |
| --- | --- |
| 触发条件 | 指定剧情或任务 |
| 前置条件 | 必须完成的事件 |
| 受益人物 | 哪名角色或哪些角色 |
| 晋升结果 | 目标大等级；仅解锁内容的事件可不含晋升 |
| 属性变化 | 生命上限、妖力或灵力的具体变化 |
| 内容奖励 | 解锁的技能、武器、装备 |
| 完成记录 | 防止重复领取永久奖励 |

成长结果写入存档。检查点重试和读档按照对应记录恢复，人物阶段、属性、内容解锁及相关任务/事件状态保持一致，避免重复晋升或重复领取永久奖励。

## 技能、武器与装备解锁

| 解锁方式 | 配置内容 |
| --- | --- |
| 剧情直接获得 | 对应剧情事件、受益人物、获得条目 |
| 特定人物授予 | 授予者、接触/互动条件、必要剧情或任务前置、获得条目 |

- 特定人物的授予可设置剧情前置；并非见到人物后即可取得其全部内容。
- 初始人物配置随人物登场/加入事件记录；后续获得按各条目的解锁条件处理。
- 删除原有花费精华提高技能等级的成长方式；不另设技能经验、使用次数熟练度或技能点的替代积累系统。
- 技能是否存在后续进阶版本、武器装备是否有后续形态尚待确定；若设置，其开放仍由指定剧情或特定人物的条件控制。
- 本轮只确定武器与装备的获得/解锁，不预设其属性加成、材料强化、随机词条或其他培养系统。

## 与基础战斗设计的关系

[基础战斗设计](combat-system-design.md)继续定义物理、妖力、灵力三种伤害及其结算。人物力量成长按对应的妖力或灵力类型分别配置，两者不互换，也不合并为统一的灵力属性。

人物大等级与“高等级灵力”的净化条件不能直接画等号。特殊净化能力是否已解锁、对应的灵力条件，以及能作用的异常/源头，按基础战斗规范和后续具体配置判断。

四魂之玉系统补充（2026-10-25）：双阵营共用本成长规则。碎片力量按人物与剧情配置有上限的暂时强化或战斗机制，持有更多碎片不直接使全队永久升级，不替代指定任务/剧情晋升及技能、武器、装备的解锁条件。碎片主动使用资格和具体效果待配置；四魂之玉的净化/污染状态不自动改变人物阶段或赋予异常净化能力。
