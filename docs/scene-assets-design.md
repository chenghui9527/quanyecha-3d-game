## 组合与互动

- 第一关开场安排食骨之井与御神木，沿后续道路布置普通大树；第二关在现有实心道路上放置四栋茅草屋。第三、四关的树木和地形按关卡色调压暗。
- 场景物件画在角色与战斗层后方。地形覆盖树根与房屋的接地边缘。现有平台高度、宽度、断崖和跳跃路线沿用现有数据。
- 大树按整片树根的宽度避让断崖，避免树根跨过缺口造成可落脚的错觉。
- 树木按宽阔根部的接地范围对齐，不以最下方的细根尖作为地面基准。`groundOverlap` 规定原尺寸下的入土深度，并随摆放比例缩放：御神木32像素、普通大树约5像素；草层覆盖入土部分。封印人物与箭沿用御神木的垂直偏移，继续贴合树干。
- 鸟居显示在角色后方，双柱石础落在原有实心路面上，上横梁完整保留在终点镜头内。鸟居是可通过的入口地标，继续沿用原章节完成条件，没有开关门状态。
- 走到门前 64 像素范围，落地时按 E / Enter 开关。按住按键只触发一次；暂停、跳跃、出招、闪避、受伤时不触发。木门当前仅改变外观，房屋内部与进出房间不在首批范围。
- 木门状态只在本次关卡停留中保留，重试或重进关卡复位，不引入存档字段。
- 普通大树、御神木、房屋和井是装饰或剧情定位单元，当前没有额外阻挡碰撞；可站立范围继续由原地图平台确定。
- 图集用透明边界提取有效画面；地形两行之间按实际透明间隔分割，避免生成结果未严格等分时裁掉岩石或混入上一行。

## 查看与验证

`scene-lab.html` 是独立场景预览页，沿用主线 Renderer、Game 和地图碰撞，使用临时队伍与空存储，不读取、写入主线进度。支持六个场景视图、角色选择、道路位置滑条、碰撞边缘与开关门演示，页面下方展示七类素材；“神社门”按钮直接定位到第一关鸟居前。

`npm run build` 同时输出可直接双击打开的 `dist/index.html`、`dist/monster-lab.html`、`dist/scene-lab.html`，场景图片完整内嵌，无运行时网络依赖。
