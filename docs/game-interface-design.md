## 妖力与灵力

用户已明确：新增条表示技能可消耗的能量储量。犬夜叉使用紫色妖力条，戈薇使用青蓝灵力条，出战与后台均保留；它与伤害计算中的力量强度分开。

本次完成条的位置与展示接口。容量、技能消耗、恢复方式及成长对容量的影响尚待配置，因此当前显示虚线槽和`— / —`，辅助说明为“暂未启用”。没有把设计图的100／80或现有`power`强度当作储量，也没有新增能量存档、扣费或恢复机制。技能继续沿用现有冷却规则。伙伴页分别列出储量占位和实际力量强度。

## 暂停、对话与触屏

Esc或右上暂停打开“旅途手记”，包含旅程、伙伴、四魂、图鉴、设置五个页签。旅程展示真实篇章、目标、本幕信物与检查点；尚未到达灯笼时明确标注本幕起点。底部提供继续、从检查点／本幕起点重试及返回首页，切页保持暂停。页签支持左右方向键、Home／End和Tab，Esc可继续；设置保留声音、全屏与存档导入／导出。战斗时按`?`或点击行动栏下方的操作入口可直接打开设置页。

对话显示人物头像、姓名、句序、全文及继续入口，隐藏战斗行动区、目标与首领条，淡化队伍摘要。继续仍调用已有剧情逻辑，未新增自动播放或对白分支。

触屏显示移动与下键，以及双技能、闪避、切换、跳跃、攻击六键；互动只在附近出现。主要行动触点为44×44像素，竖屏保留完整场景并将状态与操作安排在上下余留区，横屏六个行动键改为一行，位于路面下方，四魂摘要仍在目标卡下方。较小的键鼠窗口将切人与操作提示排到技能栏左侧，避免增加高度后挤上道路。减少动态效果设置继续有效。

## 实现与验证

界面结构在`index.html`，主线样式在`battle.css`，只读展示计算在`src/hud.js`，交互及手记在`src/main.js`。`scripts/build.mjs`将样式、图标与代码内嵌到`dist/index.html`；两个资源验证场保留自己的界面。战斗引擎、剧情配置和存档版本未修改，仍使用version 2及原本的本地存储键。

- `npm run check`、87项自动测试及`npm run build`通过。新增四项HUD检查覆盖人物重排与独立状态、未加入人物、能量与强度分离、实际目标／信物和冷却显示。
- Chrome离线实机检查双人切换、两个技能名称与冷却、首领条、场景互动和对话、手记页签与键盘切页、暂停／继续、全屏和声音入口，以及390×844竖屏、844×390触屏横屏。
- 后续技能栏调整再次检查1280×720、960×540与844×390键鼠窗口及横竖屏触控。测得技能栏上缘分别在道路碰撞线下22.4、16.8、12.7像素，包含路面纹理厚度与留白；四格完整可见，触控仍为44×44像素。
- 流程验证使用临时页面中的独立内存存储，没有以测试新旅程或导入操作覆盖用户真实进度。本轮界面检查不记作六幕完整人工通关。

当前可玩内容仍为犬主01～03六幕。能量消耗／恢复、奈落可玩路线及后续篇章继续按各自配置推进，本次完成的是已确认界面布局及现有功能的接入。
