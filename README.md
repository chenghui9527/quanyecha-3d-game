# 犬夜叉：四魂初旅

三到四头身精细像素风的 Web 单机横版剧情动作游戏。已确认以犬夜叉与奈落两套阵营剧情为核心，双方争夺同一批四魂之玉碎片，集齐的一方获胜；一期第三方视角提供进度比对面板。10阶段的两套剧情章节已正式纳入剧情基础设定v1.0，当前可玩主角线第一阶段前三篇《封印与玉碎》《逆发之森》《父亲的墓地》，共六幕，已接入剧情成长、开篇碎片、敌方事件收集与进度比对；奈落可玩路线和其余章节待后续制作。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
npm run dev
```

浏览器打开终端显示的 `http://localhost:4173`。源码入口使用 ES Modules，需要 HTTP 服务。

也可以直接打开已经打包好的 `dist/index.html`，无需启动服务。修改源码后使用 `npm run build` 更新这个独立版本。

## 全屏主界面

首页已按确认的设计图实现：森林与御神木铺满窗口，朱红与金色书法标题和旅程菜单位于左侧，底部提供「伙伴」「四魂之玉」「妖怪图鉴」，右上角提供全屏、声音和设置。无存档时显示「开始旅程」，已有进度时显示「继续旅程」和「新的旅程」；主菜单支持鼠标、Tab及上下方向键选择。

点击「全屏」可进入系统全屏，章节、档案和设置弹窗在全屏中仍可使用。战斗画面按16:9等比适配窗口；首页另有竖屏和低高度横屏布局。萤火、飘叶与薄雾为轻微动画，跟随系统的减少动态效果设置。设置中保留导入／导出存档和两个独立资源预览入口。

设计图位于 `output/main-menu/fullscreen-menu-v1.png`；书法标题使用独立透明素材，说明与提示词见[标题素材](docs/title-logo-art-prompt.md)。

## 阵营选择

点击「开始旅程」或「新的旅程」先进入全屏阵营选择。一条旅程固定一个阵营；「继续旅程」直接恢复原存档，章节重玩沿用该阵营。左右／上下方向键可切换选择，Esc返回，鼠标和触控也可使用。

犬夜叉阵营可开启前三篇；奈落阵营可选择查看介绍，标注「筹备中」，开始按钮暂不可用。已有进度时，开启前会显示当前阵营和章节，并提供返回选择、导出存档和最后确认；浏览或取消不会清空进度。新旅程会重置剧情、成长与碎片，保留声音设置。

规则、实现与素材见[阵营选择设计](docs/faction-selection-design.md)。

## 游戏内界面

已采用确认的合成紧凑版：左上为出战人物与队友，右下为普攻、闪避和双技能，顶部中央显示首领，右上显示工具与目标，左下显示四魂份额。技能面板和图案进一步缩小，固定在路面下方；完整16:9场景与人物比例保持不变，对话和触屏布局同步调整。

左下四魂卡已按参考图加入细金线角纹、蓝紫切面玉石和高光，标题、进度细线与双方份额紧凑排布；显示实际份额，点击进入四魂手记，玉碎前显示「尚未玉碎」。

右上剧情卡同步采用切角金框、角部纹饰与深色底，章节、菱形目标、信物和道路细线分层展示；长目标完整换行，首领战收起道路条，对话结束后恢复目标卡。

Esc打开「旅途手记」，可切换旅程、伙伴、公用道具、四魂、图鉴、设置，六页共用固定尺寸、标题导航及底部操作样式，切页保持暂停；按`?`可直接查看操作与设置。出战人物卡更大并以亮金框标记，切人共用1秒冷却，队友卡显示倒计时。生命、状态、技能冷却、目标和四魂份额读取实际进度。犬夜叉妖力条、戈薇灵力条按新要求默认显示100／100，标题保持单行，颜色对比度提高；这属于展示默认值，容量、消耗与恢复规则待配置。技能框使用切角金线外框并进一步缩小，卡间距收紧。详情见[游戏内界面 v1.0](docs/game-interface-design.md)。

## 人物面板与公用道具

战斗按C或Esc→伙伴打开新版人物面板，首次进入属性页，之后保留本次页签选择。左侧选人物只查看；属性、技能、六部位装备和成长分别展示真实数据。装备部位为上衣／下衣／手部／饰物／武器／足部，人物专属；安全神社附近才能更换，候选仅预览，确认后生效。Esc先取消候选，再关闭面板，继续旅程返回战斗。

公用道具位于手记一级菜单，选择物品与存活队员后确认，回到战斗施用0.6秒，成功才消耗1份。首版药草恢复40点生命，解毒药清除全部中毒；每处神社首次提供各1份。受击、切人等中断不消耗，重试时与检查点统一回退。旧存档会补齐装备与道具记录，继续使用原存储键和version 2。现有衣物没有新增强化或随机属性。

完整交互、首版数值和验证见[人物面板与公用道具](docs/character-panel-design.md)。

## 当前可玩：第一阶段前三篇

- 犬主01《封印与玉碎》：解封犬夜叉、击败村外尸舞鸦、玉碎后靠近碎片按E拾取。
- 犬主02《逆发之森》：穿越发丝陷阱、打碎结罗的三个结点，击败后按E收取碎片。
- 犬主03《父亲的墓地》：按E识破假母；切换戈薇拔出铁碎牙，迎战杀生丸并触发守护与刀的觉醒。

用户试玩反馈基本可用，当前三篇的基本流程作为后续章节制作参照。每篇两幕，完成前一幕解锁后一幕。人物按剧情成长，不再刷经验或消耗精华强化；信物仅用于收藏与星章记录。首页底部“四魂之玉”可查看双方真实份额与已知线索；前三篇结束不等于整玉集齐。

旧四关存档会自动迁移并开放第三篇。新墓地、首领形态与铁碎牙使用首版程序绘制，数值与专属美术仍待完善。具体配置和实现边界见[前三篇可玩首版](docs/opening-three-chapters.md)。

## 场景资源

首批六类资源已接入关卡：普通大树、御神木、茅草屋、开关木门、食骨之井、泥土地面与岩石平台。第一关开场可见井与神木，第二关村道布置茅草屋；走到门前按 E / Enter 开关。

现已补充神社门（鸟居）：朱红木柱、深色横梁、注连绳、纸垂与石础，用于关卡尽头的出口。

打开 `dist/scene-lab.html` 可直接预览六个场景视图、角色比例、碰撞边缘与七类独立素材；点击「神社门」可直接查看鸟居。本页不读写主线存档。首页设置中也有「场景资源预览」入口。通过本地服务运行时，对应地址为 `/scene-lab.html`。场景设计见 [场景资源](docs/scene-assets-design.md)。

## 妖怪系统

普通怪总库现有十五种：尸舞鸦、蜘蛛头、最猛胜、极乐鸟、妖鼠群，以及用户确认的十种基础小怪——赤眼多足妖、巨口长躯妖、多眼长虫、赤瞳眼球妖、巨颚甲虫妖、长舌鬼面妖、翼膜人面妖、瘤背长颈妖、青面独眼妖、骷面垂须妖。十种使用动画无名群妖外形，名称为游戏归类名；完整身体与动作的补全部分见[资源说明](docs/unnamed-monster-assets.md)。主线随对应剧情开放，当前前三篇的投放继续沿用既定布局；菜单中的「妖怪」在首次击败后收录条目并保存。

打开 [十种基础小怪资源预览](assets/monsters/preview.html) 可循环查看80个姿势、定格攻击、切换左右朝向，并打开透明PNG和独立取帧文件。全部资源位于 `assets/monsters/`；生成提示词保存于 [提示词集](docs/unnamed-monster-generation-prompts.json)。

无名群妖[动画参考清单](docs/references/unnamed-yokai/review.html)共十种均已审核采用并制作；新增07～10（翼膜人面、瘤背长颈、青面独眼、骷面垂须）来自第24、28话。

直接打开 `dist/monster-lab.html` 可查看犬夜叉的三段普攻、上挑、空中追打、下砸、散魂铁爪和飞刃血爪，支持完整连招演示、慢动作、出手定格与耐打练习目标。也可选择十五种怪物的单只、3只、5只或混合组合，以及妖鼠连续3波；可选四组基础小怪混合组合。验证场使用临时队伍，不读写主线进度。通过本地服务运行时，对应地址为 `/monster-lab.html`。

## 操作

新增C人物面板快捷键；Esc在装备候选或道具目标层先返回。

| 按键 | 操作 |
| --- | --- |
| A / D 或方向键 | 移动 |
| Space / W / ↑ | 跳跃 |
| J | 普通攻击（可按住） |
| S / ↓ ＋ J | 犬夜叉地面上挑；空中下砸 |
| 跳跃后 J | 犬夜叉空中追打 |
| K / Shift | 闪避 |
| U | 主动技能 |
| I | 第二技能 |
| 1 / 2 或 Tab | 切换角色 |
| E / Enter | 互动、继续对话 |
| Esc | 暂停／继续，打开旅途手记 |
| ? | 操作与设置 |

游戏在浏览器本地保存进度，暂停菜单可以导出/导入存档。关卡选择支持重玩已经解锁的关卡。
